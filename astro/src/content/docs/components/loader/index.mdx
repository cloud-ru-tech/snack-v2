# Loader

The Loader package provides loading indicators: **Spinner** (circular) and **Sun** (sunburst). Both support multiple sizes and are used to indicate loading or progress.

**Version:** `{frontmatter.version}`

## Installation

```bash
npm install @design-system/loader
# or
yarn add @design-system/loader
# or
pnpm add @design-system/loader
```

## Overview

Loader components are used to show that content is loading. The package includes:

- **Spinner** — Circular loading indicator with sizes from 2xs to l
- **Sun** — Sunburst-style loading indicator with sizes xs to l
- **Multiple sizes** — 2XS, XS, S, M, L (Spinner); XS, S, M, L (Sun)
- **Accessibility** — Decorative SVGs with appropriate attributes
