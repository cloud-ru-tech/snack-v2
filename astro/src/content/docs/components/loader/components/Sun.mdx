## Accessibility

- Loader is decorative; use `aria-hidden="true"` or `role="img"` with `aria-label="Loading"` when it is the only indicator
- Prefer pairing with visible text (e.g. "Loading…") for screen readers

## Best practices

1. **Match size to context** — Use smaller sizes (XS, S) inline; M/L for full-page or prominent loading
2. **Provide context** — Combine with text or `aria-live` so screen reader users know loading is in progress
