# Drawer

Выезжающая панель для вторичного контекста: фильтры, детали объекта, мастер-шаги, настройки. Компонент **Drawer** собирает шапку: опциональный медиа-слот (`media`), заголовок и подзаголовок, кнопку «назад», слот после заголовка (`slotAfterHeadline`), прокручиваемое тело и опциональный футер. Низкоуровневая сборка без фиксированной шапки — через **DrawerCustom** и субкомпоненты `Header`, `Body`, `Footer`.

## Overview

**Drawer** строится на [rc-drawer](https://github.com/react-component/drawer) и интегрируется с утилитами дизайн-системы (`useModalOpenState`, `extractSupportProps`). Панель монтируется в портал (по умолчанию `document.body` или свой контейнер через `container`), при закрытии контент уничтожается (`destroyOnClose`).

Компонент обеспечивает:

- **Четыре стороны появления** — `position`: `left`, `right`, `top`, `bottom` (через `placement` у rc-drawer).
- **Ширина слева/справа** — пресеты `'s' | 'm' | 'l'` или произвольное значение (`width`), см. константы `WIDTH` в пакете.
- **Высота сверху/снизу** — при `heightAuto` панель подстраивается под контент в пределах экрана; для боковых панелей не используется.
- **Подложка и закрытие** — при `showBlackout` (по умолчанию `true`) маска кликабельна, закрытие по Escape и клику по маске; кнопка закрытия в углу панели.
- **Медиа и шапка** — `media` для блока над шапкой (превью, иллюстрация) и `slotAfterHeadline` для узла в одной строке с заголовком (иконка подсказки, бейдж и т.п.).
- **Кастомная вёрстка** — `DrawerCustom` + `DrawerCustom.Header` / `Body` / `Footer` для полного контроля над разметкой.

## Usage

### Базовый пример

```tsx
import { Drawer } from '@design-system/drawer';
import { useState } from 'react';

export function Example() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button type='button' onClick={() => setOpen(true)}>
        Открыть
      </button>
      <Drawer
        open={open}
        onClose={() => setOpen(false)}
        position='right'
        title='Заголовок'
        content={<p>Контент</p>}
      />
    </>
  );
}
```

### С футером и кнопкой «назад»

Передайте `footer` с произвольной разметкой (например, группу кнопок). Чтобы показать стрелку «назад» в шапке, задайте `onBackButtonClick`.

```tsx
import { Drawer } from '@design-system/drawer';
import { useState } from 'react';

export function Example() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button type='button' onClick={() => setOpen(true)}>
        Открыть
      </button>
      <Drawer
        open={open}
        onClose={() => setOpen(false)}
        position='left'
        title='Редактирование'
        onBackButtonClick={() => setOpen(false)}
        content={<form>{/* поля */}</form>}
        footer={<div className='actions'>{/* кнопки сохранения */}</div>}
      />
    </>
  );
}
```

### DrawerCustom

Когда нужна своя структура без готовой шапки Drawer, используйте `DrawerCustom` и субкомпоненты:

```tsx
import { DrawerCustom } from '@design-system/drawer';
import { useState } from 'react';

export function Example() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button type='button' onClick={() => setOpen(true)}>
        Открыть
      </button>
      <DrawerCustom open={open} onClose={() => setOpen(false)} position='right' width='m'>
        <DrawerCustom.Header title='Заголовок' />
        <DrawerCustom.Body content={<div>Произвольный контент</div>} />
        <DrawerCustom.Footer>Панель действий</DrawerCustom.Footer>
      </DrawerCustom>
    </>
  );
}
```

### Портал и история браузера

Для вложенного портала (например, из `usePortalContext`) передайте `container`. Чтобы закрывать панель при навигации по истории, используйте `closeOnPopstate` (через `useModalOpenState` внутри `DrawerCustom`).

## Accessibility

- Кнопка закрытия панели имеет осмысленный `aria-label` (`close drawer`).
- При включённой маске (`showBlackout`) закрытие по **Escape** и клику по подложке согласовано с поведением rc-drawer (`keyboard`, `maskClosable`).
- Тело панели обёрнуто в компонент **Scroll** с прокруткой — длинный контент остаётся доступным с клавиатуры при фокусируемых элементах внутри.
- Заголовок и подзаголовок рендерятся через **Typography**; при необходимости свяжите панель с видимым заголовком страницы (управление фокусом при открытии — на стороне сценария и библиотеки drawer).

## Best practices

1. **Держите состояние снаружи** — `open` и `onClose` должны отражать единый источник правды (URL, store, родительский layout), чтобы панель не «залипала» при ре-рендерах.
2. **Не дублируйте логику закрытия** — для согласованного поведения с модалками дизайн-системы используйте `closeOnPopstate`, если панель должна закрываться при `popstate`.
3. **Боковая vs верхняя/нижняя** — для `top` / `bottom` явно решайте, нужна ли `heightAuto`, и проверяйте переполнение на маленьких экранах; для `left` / `right` опирайтесь на `width` (пресеты или число в пикселях).
4. **Футер для основных действий** — размещайте подтверждение и отмену в `footer`, чтобы они оставались на виду при прокрутке тела.
