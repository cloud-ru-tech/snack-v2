# Slider

Пакет содержит компонент **Slider** на базе `rc-slider`: одиночное значение или диапазон, подписи шкалы (`marks`), опциональный тултип на ручке. Стили темы — класс `dsThemeSlider` на корне компонента.

**Version:** `{frontmatter.version}`

## Installation

```bash
npm install @design-system/slider
# or
yarn add @design-system/slider
# or
pnpm add @design-system/slider
```

## Overview

- **Slider** — обёртка над `rc-slider` с теми же пропами (кроме вертикального режима и инлайн-стилей трека/ручки), плюс `handleTip`, `tipFormatter` и **`marksEqualSpacing`** для равномерного распределения подписей при нелинейных значениях меток.
- Стили темы: класс `dsThemeSlider` на корне.
