# Popover Private

Низкоуровневый компонент поповера на базе Floating UI. Используется для построения Tooltip, Dropdown и других overlay-компонентов. Поддерживает триггеры click, hover, focus, гибкое позиционирование и опциональную стрелку.

## Overview

Popover Private — низкоуровневый компонент поповера на базе [Floating UI](https://floating-ui.com/). Предназначен для сборки Tooltip, Dropdown, меню и других overlay-компонентов. Не содержит собственных стилей контента: оформление задаётся через `className` и контент (`popoverContent`).

Компонент обеспечивает:

- **Триггеры открытия** — `click`, `hover`, `focus`, `focusVisible` и их комбинации (`hoverAndFocus`, `clickAndFocusVisible` и др.). Для hover настраиваются задержки открытия и закрытия (`hoverDelayOpen`, `hoverDelayClose`).
- **Позиционирование** — 12 вариантов `placement` (top, bottom, left, right и их -start/-end). При нехватке места срабатывает flip по цепочке `fallbackPlacements`.
- **Размеры контейнера** — стратегии ширины (`auto`, `gte`, `eq`) и высоты (`auto`, `lte`, `eq`) для привязки к размеру триггера или контенту.
- **Опциональная стрелка** — `hasArrow`, стилизация через `arrowContainerClassName` и `arrowElementClassName`.
- **Управление** — контролируемый режим (`open` + `onOpenChange`) или неконтролируемый. Закрытие по клику вне (`outsideClick`), по Escape (`closeOnEscapeKey`), при навигации по истории (`closeOnPopstate`).
- **Триггер** — в качестве `children` передаётся элемент или render-функция `(getReferenceProps, ref) => ReactNode`; при необходимости можно использовать только `triggerRef` без `children`.

## Usage

### Basic example

```tsx
import { PopoverPrivate } from '@design-system/popover-private';

export function Example() {
  return (
    <PopoverPrivate
      trigger='click'
      placement='top'
      popoverContent={<div>Контент поповера</div>}
    >
      <button type="button">Открыть</button>
    </PopoverPrivate>
  );
}
```

### With additional props

```tsx
import { PopoverPrivate } from '@design-system/popover-private';

export function Example() {
  return (
    <PopoverPrivate
      trigger='hover'
      placement='top'
      hasArrow
      outsideClick
      popoverContent={
        <div style={{ padding: 12, borderRadius: 8 }}>
          Дополнительная информация
        </div>
      }
    >
      <button type="button">Подсказка</button>
    </PopoverPrivate>
  );
}
```

## Accessibility

- **Триггер с клавиатуры** — в качестве триггера используйте элемент, доступный с клавиатуры (например, `<button>`) или элемент с `tabIndex={0}` и обработчиками клавиш. При `trigger="click"` по умолчанию поповер открывается и закрывается по Enter/Space (`triggerClickByKeys`).
- **Закрытие по Escape** — по умолчанию поповер закрывается по Escape (`closeOnEscapeKey`). Не отключайте без веской причины.
- **Триггеры для подсказок** — для тултипов и подсказок предпочтительны `focusVisible` или `hoverAndFocusVisible`, чтобы контент был доступен и при навигации с клавиатуры.
- **Семантика контента** — контейнер поповера имеет `role="presentation"`. Роль, `aria-*` и разметку задавайте в контенте (`popoverContent`) в зависимости от сценария: например, `role="menu"` и `aria-orientation` для меню, описание для тултипа через `aria-describedby` на триггере.
- **Поддержка атрибутов** — компонент поддерживает `data-test-id` и другие атрибуты через `WithSupportProps` для тестов и кастомизации.

## Best practices

1. **Выбор триггера** — используйте `click` для выпадающих меню и действий с выбором; `hover` или `hoverAndFocusVisible` для подсказок и дополнительной информации, чтобы не перегружать интерфейс кликами.
2. **Закрытие и границы экрана** — включайте `outsideClick: true` для закрытия по клику вне поповера. Задавайте `fallbackPlacements`, чтобы при нехватке места поповер переворачивался в подходящую сторону, а не уходил за край вьюпорта.
3. **Низкоуровневый слой** — не используйте Popover Private как готовый UI-блок. Стройте на нём компоненты уровня Tooltip, Dropdown, Menu с нужными стилями, ролями и описаниями для скринридеров.
