# Pagination

Компоненты пагинации для постраничной навигации: выбор страницы по номерам с стрелками и опциональным троеточием, либо индикатор в виде точек (слайдер).

## Overview

Пакет экспортирует два компонента:

- **Pagination** — классическая пагинация: кнопки «Назад»/«Вперёд» и номера страниц. При большом числе страниц показывается троеточие (`...`), по клику — переход к странице из скрытого диапазона. Поддерживает размеры `s` | `m` и вариант рендера: `button` (по умолчанию) или `link` (ссылки для SEO/доступности).
- **PaginationSlider** — компактный индикатор в виде точек: одна точка на страницу, активная страница выделена. Подходит для каруселей и слайдеров. Размеры: `xs` | `s`.

Особенности:

- Стилизация через токены `@sbercloud/figma-variables`, соответствие макету Figma.
- Управление фокусом при переходах (Pagination).
- Опциональный `hrefFormatter` для рендера страниц как ссылок (Pagination).
- Семантическая разметка: `<nav>`, `aria-label`, `aria-current="page"` для текущей страницы.

## Usage

### Pagination (базовый пример)

```tsx
import { useState } from 'react';
import { Pagination } from '@design-system/pagination';

export function Example() {
  const [page, setPage] = useState(1);
  return (
    <Pagination
      total={100}
      page={page}
      onChange={setPage}
    />
  );
}
```

### Pagination с размерами и вариантом link

```tsx
import { Pagination, PAGINATION_SIZE, VARIANT } from '@design-system/pagination';

<Pagination
  total={20}
  page={5}
  size={PAGINATION_SIZE.M}
  variant={VARIANT.Link}
  hrefFormatter={(page) => `/posts?page=${page}`}
  onChange={(page) => router.push(`/posts?page=${page}`)}
/>
```

### PaginationSlider

```tsx
import { useState } from 'react';
import { PaginationSlider, PAGINATION_SLIDER_SIZE } from '@design-system/pagination';

export function CarouselExample() {
  const [slide, setSlide] = useState(0);
  return (
    <>
      {/* Контент карусели */}
      <PaginationSlider
        total={7}
        page={slide}
        size={PAGINATION_SLIDER_SIZE.S}
        onChange={setSlide}
      />
    </>
  );
}
```

## API

### Pagination

| Prop | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `total` | `number` | — | Общее количество страниц |
| `page` | `number` | — | Текущая страница |
| `onChange` | `(page: number, event?) => void` | — | Колбэк при смене страницы |
| `size` | `'s' \| 'm'` | `'s'` | Размер кнопок и номеров |
| `variant` | `'button' \| 'link'` | `'button'` | Рендер номеров как `<button>` или `<a>` |
| `maxLength` | `number` | `7` | Макс. число видимых элементов до появления троеточия |
| `hrefFormatter` | `(page: number) => string` | — | Формат `href` для варианта `link` |
| `className` | `string` | — | Дополнительный класс для `<nav>` |

### PaginationSlider

| Prop | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `total` | `number` | — | Количество страниц (точек) |
| `page` | `number` | — | Текущая страница |
| `onChange` | `(page: number) => void` | — | Колбэк при выборе страницы |
| `size` | `'xs' \| 's'` | `'xs'` | Размер точек |
| `className` | `string` | — | Дополнительный класс для `<nav>` |

## Accessibility

- Используется семантический `<nav>` с `aria-label="Pagination"` / `aria-label="Pagination slider"`.
- Текущая страница помечается `aria-current="page"`.
- Кнопки «Назад»/«Вперёд» имеют подписи `aria-label="Previous page"` и `aria-label="Next page"`.
- Фокус после перехода по стрелкам или троеточию перемещается на соответствующую кнопку страницы.
- Поддержка `variant="link"` и `hrefFormatter` позволяет делать номера страниц ссылками для SEO и навигации без JavaScript.

## Best practices

1. **Контролируемое состояние** — храните `page` в состоянии родителя и передавайте в `page` + `onChange`, чтобы синхронизировать пагинацию с данными (список, таблица).
2. **Pagination для списков/таблиц** — используйте `Pagination`, когда важно показывать номера страниц и переходить «в середину» (например, в каталогах, админках).
3. **PaginationSlider для каруселей** — используйте `PaginationSlider`, когда страниц немного и нужен компактный индикатор (слайдеры, онбординг).
4. **SEO** — для индексации страниц используйте `variant="link"` и `hrefFormatter`, чтобы номера были ссылками с осмысленными URL.
