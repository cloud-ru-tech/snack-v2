# Timeline

Пакет содержит публичный компонент **Timeline** (лента шагов) и внутренний **TrackItem** (строка пункта с колонкой маркера и линиями). API и поведение согласованы с `@snack-uikit/timeline`; стилизация — через `@sbercloud/figma-variables`.

**Version:** `{frontmatter.version}`

## Installation

```bash
npm install @design-system/timeline
# or
yarn add @design-system/timeline
# or
pnpm add @design-system/timeline
```

## Overview

- **Timeline** — массив `items` с `content` (ReactNode), опционально `opposite`, `lineStyle`, `dotVariant`, `dotAppearance`; режимы `contentPosition`, `alternate`, `fullWidth`; роли и линии между пунктами вычисляются автоматически.
- **TrackItem** — одна строка таймлайна (контент + трек); не экспортируется из корня пакета, но доступен для кастомных сценариев из исходников (см. страницу компонента).
