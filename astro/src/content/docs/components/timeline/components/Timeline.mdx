# Timeline

Компонент **Timeline** рендерит список шагов. Для каждого элемента задаётся **`content`** (обычно заголовок и описание). Система сама назначает роль точки (**start** / **center** / **end**), рисует соединительные линии (при более чем одном пункте) и поддерживает **`alternate`** для чередования сторон контента.

### Стабильные ключи при изменении порядка

Внутри `Timeline` пункты рендерятся с `key={index}`. Если порядок шагов меняется (сортировка, drag-and-drop), храните стабильные id в своём состоянии и собирайте массив `items` из актуального порядка идентификаторов — так содержимое пунктов остаётся согласованным с данными.

```tsx
const items = orderedStepIds.map(id => {
  const step = stepsById[id];

  return {
    content: <StepCard title={step.title} />,
    dotAppearance: step.done ? 'green' : undefined,
  };
});

return <Timeline items={items} />;
```

## Usage

### Базовый пример

```tsx
import { Typography } from '@design-system/typography';
import { Timeline } from '@design-system/timeline';

export function Example() {
  return (
    <Timeline
      items={[
        {
          content: (
            <>
              <Typography variant='title' size='m'>
                Шаг 1
              </Typography>
              <Typography variant='body' size='m'>
                Описание
              </Typography>
            </>
          ),
          dotAppearance: 'primary',
        },
        {
          content: (
            <>
              <Typography variant='title' size='m'>
                Шаг 2
              </Typography>
              <Typography variant='body' size='m'>
                Ещё текст
              </Typography>
            </>
          ),
          lineStyle: 'dashed',
        },
      ]}
    />
  );
}
```

### Чередование и полная ширина

```tsx
<Timeline items={items} alternate contentPosition="right" />
<Timeline items={items} fullWidth />
```

### Пункт с под-событием и цветом точки

```tsx
<Timeline
  items={[
    {
      content: <>{/* ... */}</>,
      lineStyle: 'dashed',
      dotVariant: 'subEvent',
      dotAppearance: 'red',
    },
  ]}
/>
```

## Accessibility

- Контент в **`content`** формируйте семантично (заголовки, параграфы), чтобы скринридеры получали осмысленную структуру.

## Best practices

1. **Стабильные ключи** — в текущей реализации список рендерится с `key={index}`; при динамической перестановке пунктов рассмотрите обёртку со своими ключами на стороне продукта.
2. **Длинный текст** — допускается многострочный `content`; высота строки задаётся контентом, трек растягивается по высоте строки.
3. **Один пункт** — линии между шагами скрываются (`showLines` внутри выключается), остаётся только маркер.
