## Usage

### Basic

```tsx
import { ProgressBarCircle } from '@design-system/progress-bar';

export function Example() {
  return <ProgressBarCircle progress={50} size="s" appearance="primary" />;
}
```

### Default appearance

```tsx
import { ProgressBarCircle } from '@design-system/progress-bar';

export function Example() {
  return <ProgressBarCircle progress={75} size="s" />;
  // appearance по умолчанию — primary
}
```

## Accessibility

- Компонент использует семантическую разметку и ARIA-атрибуты для индикатора прогресса
- Рекомендуется сопровождать индикатор текстом или `aria-label` с текущим значением для пользователей скринридеров

## Best practices

1. **Указывайте прогресс явно** — Всегда передавайте `progress` в диапазоне 0–100
2. **Подбирайте appearance** — По умолчанию primary; используйте цветные варианты для статуса
3. **Размер по контексту** — XS для компактных мест (карточки, виджеты), S для основных экранов
