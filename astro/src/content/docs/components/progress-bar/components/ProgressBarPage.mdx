# ProgressBarPage

Индикатор загрузки страницы: отображается фиксированно вверху экрана при включённом состоянии. Подходит для глобальной индикации загрузки (например, при переходе между страницами или фоновых запросах).

## Usage

### Basic

```tsx
import { ProgressBarPage } from '@design-system/progress-bar';
import { useState } from 'react';

export function Layout() {
  const [loading, setLoading] = useState(true);

  return (
    <>
      <ProgressBarPage inProgress={loading} appearance="primary" />
      {/* контент страницы */}
    </>
  );
}
```

### With timing options

```tsx
import { ProgressBarPage } from '@design-system/progress-bar';

export function Example() {
  return (
    <ProgressBarPage
      inProgress={true}
      appearance="primary"
      animationDuration={200}
      incrementDuration={800}
      minimum={0.08}
    />
  );
}
```

## Accessibility

- Используется семантическая разметка индикатора прогресса; при необходимости добавьте контекст для скринридеров (например, объявление о загрузке страницы)

## Best practices

1. **Один индикатор на приложение** — Размещайте ProgressBarPage на уровне layout (корень или обёртка маршрутов)
2. **Синхронизация с загрузкой** — Передавайте `inProgress={true}` только пока идёт реальная загрузка; по завершении переключайте на `false`
3. **Тонкая настройка** — Используйте `animationDuration` и `incrementDuration` для согласования с UX; `minimum` задаёт начальный визуальный порог (0–1)
