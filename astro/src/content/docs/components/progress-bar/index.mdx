# Progress Bar

Пакет содержит компоненты для отображения прогресса операции: линейный индикатор **ProgressBar**, круговой **ProgressBarCircle** и индикатор загрузки страницы **ProgressBarPage**.

**Version:** `{frontmatter.version}`

## Installation

```bash
npm install @design-system/progress-bar
# or
yarn add @design-system/progress-bar
# or
pnpm add @design-system/progress-bar
```

## Overview

Компоненты пакета используются для визуализации прогресса (0–100%) или состояния загрузки:

- **ProgressBar** — линейный индикатор прогресса, два размера (XS, S), несколько цветовых схем (appearance)
- **ProgressBarCircle** — круговой индикатор прогресса с теми же размерами и вариантами оформления
- **ProgressBarPage** — индикатор загрузки страницы (неопределённый прогресс), с анимацией и настройкой скорости

Общие возможности: единая палитра `appearance` (neutral, primary, red, green и др.), доступность, константы `PROGRESS_BAR_SIZE` и `APPEARANCE` для типизации.
