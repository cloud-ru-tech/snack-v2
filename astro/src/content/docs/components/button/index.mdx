# Button

Пакет содержит компоненты **Button** (кнопка с поддержкой view, appearance, иконок, counter) и **ButtonGroup** (группа primary + secondary кнопок). Используются в InfoBlock, формах и других интерфейсах.

**Version:** `{frontmatter.version}`

## Installation

```bash
npm install @design-system/button
# or
yarn add @design-system/button
# or
pnpm add @design-system/button
```

## Overview

- **Button** — кнопка с view (filled, outline, simple, tonal, elevated, function), appearance (primary, neutral, critical), иконками, counter, полиморфным `as` (button/a/Link). Figma: [Button](https://www.figma.com/design/aNPU3MHwRJiEwbk5F82zux/Snack-Ui-Kit-variables?node-id=2782-111011)
- **ButtonGroup** — группа primaryAction (filled), secondaryAction (outline), tertiaryAction (simple). Поддерживает size, vertical, centered, break, filled. Figma: [ButtonGroup](https://www.figma.com/design/aNPU3MHwRJiEwbk5F82zux/Snack-Ui-Kit-variables?node-id=9099-51008)
