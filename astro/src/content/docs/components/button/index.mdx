# Button

Кнопка для действий в интерфейсе. Поддерживает текст (label), иконку (icon + iconPosition: before | after), счётчик (counter), варианты оформления (view: filled, outline, simple, tonal, elevated, function) и семантические цвета (appearance: primary, neutral, critical). Полиморфный проп **as** позволяет рендерить кнопку как ссылку (`as="a"`) или как компонент роутера (например `as={Link}` из react-router-dom). Состояния: disabled, loading, fullWidth.

**Version:** `{frontmatter.version}`

Поддерживает:

- **View** — filled, outline, simple, tonal, elevated, function (по умолчанию elevated)
- **Appearance** — primary, neutral, critical
- **Размеры** — s, m, l
- **Иконка** — icon + iconPosition (before | after), например из `@design-system/icons`
- **Counter** — инлайн после текста без иконки или при iconPosition=before; при iconPosition=after — бейдж абсолютно относительно иконки
- **As** — полиморфный рендер: `'button'` (по умолчанию), `'a'` (ссылка с href/target) или кастомный компонент (напр. Link из react-router-dom)
- **Состояния** — disabled, loading, fullWidth
- Figma: [Button](https://www.figma.com/design/aNPU3MHwRJiEwbk5F82zux/Snack-Ui-Kit-variables?node-id=2782-111011)

## Overview

Button по умолчанию рендерит семантичный `<button>`; с `as="a"` — `<a>`, с `as={Component}` — переданный компонент (например Link из react-router-dom). Data-атрибуты задают стилизацию (size, appearance, view, variant). Контент — слой с state layer для hover/pressed (кроме function). Иконки и label наследуют цвет от темы.

- **View** — тип поверхности: filled (заливка), outline (обводка), simple/tonal/elevated (без заливки / с тенью), function (текстовый акцент).
- **As** — при `as="a"` передавайте `href`, при необходимости `target`, `download`; при `as={Link}` — пропсы роутера (`to`, `replace` и т.д.). При `disabled` у ссылки вызывается preventDefault.
- **Counter** — при переданном `counter={{ value: number }}`: без иконки или при iconPosition=before — счётчик в потоке контента после текста; при iconPosition=after — счётчик как бейдж в правом верхнем углу относительно иконки (пакет `@design-system/counter`).
- **Loading** — при `loading={true}` отображается индикатор загрузки (Sun), клик недоступен.

## Usage

### Basic example

```tsx
import { Button } from '@design-system/button';

export function Example() {
  return <Button label='Submit' />;
}
```

### View and appearance

```tsx
import { Button } from '@design-system/button';

export function Example() {
  return (
    <>
      <Button label='Filled' view='filled' appearance='primary' />
      <Button label='Outline' view='outline' appearance='neutral' />
    </>
  );
}
```

### With counter

Без иконки или при iconPosition=before — счётчик инлайн после текста. При iconPosition=after — счётчик как бейдж у иконки.

```tsx
import { Button } from '@design-system/button';
import { SomeIcon } from '@design-system/icons';

// Инлайн после текста
<Button label="Уведомления" counter={{ value: 5 }} />

// Бейдж относительно иконки
<Button label="Уведомления" icon={<SomeIcon />} iconPosition="after" counter={{ value: 9 }} />
```

### With icons

```tsx
import { Button } from '@design-system/button';
import { PlaceholderSVG } from '@design-system/icons';

<Button label='Сохранить' icon={<PlaceholderSVG />} iconPosition='before' view='filled' />;
```

### As link

```tsx
import { Button } from '@design-system/button';

<Button as='a' href='/about' label='О нас' view='filled' />
<Button as='a' href='https://example.com' target='_blank' label='Внешняя ссылка' view='outline' />
```

### As react-router Link

```tsx
import { Button } from '@design-system/button';
import { Link } from 'react-router-dom';

<Button as={Link} to='/dashboard' label='В кабинет' view='outline' />;
```

## Accessibility

- Рендер как нативный `<button>` (по умолчанию) — корректная семантика и фокус по клавиатуре (Tab, Enter/Space). При `as="a"` — семантика ссылки.
- Состояние `disabled` блокирует клик и отображается визуально; при `loading` кнопка остаётся в DOM с `aria-busy` для скринридеров. У ссылки при disabled используется `aria-disabled` и preventDefault.
- Для кнопки только с иконкой (icon only) передавайте `aria-label`, чтобы озвучить назначение.
- Цвета и контраст задаются через design tokens (view/appearance) в соответствии с темой.

## Best practices

1. **Выбор view** — используйте filled для основного действия, outline или simple для вторичных, function для текстовых/иконковых действий в тулбарах.
2. **Counter** — передавайте counter только когда значение несёт смысл (уведомления, количество). Без иконки или с iconPosition=before счётчик идёт после текста; с iconPosition=after — бейдж у иконки, не перекрывая подпись.
3. **Loading** — включайте `loading` на время асинхронного действия (отправка формы, загрузка), чтобы избежать повторных кликов.
4. **Иконки** — используйте иконки из `@design-system/icons` одного размера; для icon-only задавайте `aria-label`.
5. **Кнопка как ссылка** — для навигации используйте `as="a"` с `href` или `as={Link}` с `to` (react-router-dom); при `disabled` ссылка не ведёт по адресу (preventDefault).
