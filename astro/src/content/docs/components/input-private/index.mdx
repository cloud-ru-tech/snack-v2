# Input Private

Примитивный (private) компонент поля ввода — базовый `<input>` с единым стилем дизайн-системы, без обёрток (label, hint, error). Предназначен для использования внутри других компонентов (Input, InputPhone, Search и т.п.) или когда нужен минималистичный инпут с поддержкой темы и data-атрибутов.

## Overview

Input Private — это контролируемый примитив поля ввода на основе нативного `<input>`. Компонент:

- **Стили из дизайн-системы** — цвет текста и disabled-состояние через переменные темы (`@sbercloud/figma-variables`), без границ и фона, `width: 100%`
- **Типы и inputMode** — поддержка `text`, `password`, `number`, `tel`, `email`, `url` и соответствующих режимов экранной клавиатуры
- **onChange(value, e?)** — колбек получает значение строкой и опционально событие
- **Support props** — прокидывание `data-test-id` и других data-атрибутов через `extractSupportProps` из `@design-system/utils`
- **Ref** — поддержка `forwardRef` на `HTMLInputElement`

Дополнительно пакет экспортирует хуки `useClearButton`, `useButtonNavigation`, хелперы для работы с курсором и константы размеров/типов для построения составных полей ввода.

## Usage

### Basic example (controlled)

Компонент контролируемый: обязательны `value` и `onChange`.

```tsx
import { useState } from 'react';
import { InputPrivate } from '@design-system/input-private';

export function Example() {
  const [value, setValue] = useState('');
  return (
    <InputPrivate
      value={value}
      onChange={setValue}
      placeholder="Введите текст"
    />
  );
}
```

### With type and inputMode

Для паролей, email, телефона или чисел задайте `type` и при необходимости `inputMode` (влияет на клавиатуру на мобильных).

```tsx
import { InputPrivate } from '@design-system/input-private';
import { TYPE, INPUT_MODE } from '@design-system/input-private';

<InputPrivate
  type={TYPE.Password}
  value={password}
  onChange={setPassword}
  placeholder="Пароль"
/>

<InputPrivate
  type={TYPE.Tel}
  inputMode={INPUT_MODE.Tel}
  value={phone}
  onChange={setPhone}
  placeholder="+7 (999) 000-00-00"
/>
```

### With ref

Доступ к DOM-элементу через `ref` для фокуса или измерения.

```tsx
import { useRef } from 'react';
import { InputPrivate } from '@design-system/input-private';

function Example() {
  const inputRef = useRef<HTMLInputElement>(null);
  const focusInput = () => inputRef.current?.focus();
  return (
    <>
      <InputPrivate ref={inputRef} value="" onChange={() => {}} />
      <button type="button" onClick={focusInput}>Фокус в поле</button>
    </>
  );
}
```

## Accessibility

- Используется нативный `<input>`, поэтому семантика и поведение браузера (скринридеры, автозаполнение, клавиатура) сохраняются
- Для доступности оборачивайте Input Private в компонент с `<label>`, `aria-describedby` (подсказки, ошибки) и при необходимости `aria-invalid` — сам примитив не добавляет обёртку с подписью
- При использовании `placeholder` не полагайтесь на него как на единственную подсказку: добавьте видимый label или `aria-label`

## Best practices

1. **Контролируемый режим** — всегда передавайте `value` и `onChange`; для неконтролируемого сценария используйте обёртку с `defaultValue` и внутренним state
2. **Тип и inputMode** — задавайте `type` и при необходимости `inputMode` под тип данных (пароль, email, телефон, число), чтобы на мобильных открывалась подходящая клавиатура
3. **Обёртка для форм** — для полноценного поля ввода (подпись, ошибка, хинт) используйте компоненты уровня Input/InputPhone и т.д., которые внутри применяют Input Private
