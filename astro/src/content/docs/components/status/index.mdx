# Status

Пакет содержит компоненты для отображения статуса: **Status** (индикатор с подписью) и **StatusIndicator** (только точка).

**Version:** `{frontmatter.version}`

## Installation

```bash
npm install @design-system/status
# or
yarn add @design-system/status
# or
pnpm add @design-system/status
```

## Overview

Компоненты пакета используются для визуальной индикации состояния (активен, в работе, завершён и т.д.):

- **Status** — индикатор с подписью (точка + текст), два размера (XS, S), варианты: точка, загрузка (Spinner), прогресс (ProgressBarCircle)
- **StatusIndicator** — только точка-индикатор, несколько размеров (4xs–s), несколько цветовых схем (appearance)

Общие возможности: единая палитра `appearance` (neutral, primary, red, green и др.), доступность, константы `STATUS_SIZE`, `STATUS_INDICATOR_SIZE` и `APPEARANCE` для типизации.
