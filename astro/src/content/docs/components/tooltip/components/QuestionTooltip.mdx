## Accessibility

- Триггер — кнопка с `aria-label` (по умолчанию «Подсказка»), задаётся через `triggerLabel`. Иконка наследует цвет текста (`currentColor`).
- По умолчанию `trigger="hoverAndFocusVisible"` — тултип доступен при наведении и при фокусе с клавиатуры.
- Для контента внутри тултипа используйте осмысленный текст; при длинном или интерактивном контенте рассмотрите Popover с открытием по клику.

## Best practices

1. **Краткий текст** — используйте для коротких пояснений к полям, меткам или настройкам.
2. **Осмысленный triggerLabel** — задайте `triggerLabel` под контекст (например, «Подсказка о сумме»), чтобы скринридеры озвучивали назначение кнопки.
3. **Триггер по контексту** — на десктопе удобен hover; для тач-устройств можно использовать `trigger={TRIGGER.Click}`.
