## Overview

Scroll оборачивает контент в область с прокруткой и кастомными скроллбарами. Компонент:

- **Кастомные скроллбары** — размеры `s` и `m`, темизация через Figma-токены (anatomy container + slider, цвета темы).
- **Автоскрол** — при маунте и при изменении размера контента можно автоматически скроллить вниз (`bottom`) или вправо (`right`); удобно для логов и чатов.
- **Видимость скроллбаров** — стратегии: всегда показывать (`never`), скрывать при уходе курсора (`leave`), показывать только при скролле (`scroll`) или при движении курсора над областью (`move`).
- **Resize** — опциональная возможность изменять размер контейнера по горизонтали, вертикали или в обе стороны.
- **Ref** — через `ref` доступен viewport-элемент (DOM-узел прокручиваемой области).

Дополнительно экспортируется `setNonce` для установки nonce инлайн-стилей OverlayScrollbars (полезно при CSP).

## Live examples

### Basic example

Контейнеру нужна явная высота и ширина (или размер через layout), иначе скролл не появится. Для отображения скроллбара в примерах ниже используется `barHideStrategy="never"`.

<ExampleContainer>
  <ScrollBasicExample client:load/>
</ExampleContainer>

```tsx
import { Scroll } from '@design-system/scroll';

function Example() {
  return (
    <div style={{ height: 200 }}>
      <Scroll barHideStrategy='never'>
        <div>Long content...</div>
      </Scroll>
    </div>
  );
}
```

### Автоскролл вниз (логи, чат)

При маунте и при добавлении контента (если пользователь уже у нижнего края) область прокручивается вниз.

<ExampleContainer>
  <ScrollAutoscrollToBottomExample client:load />
</ExampleContainer>

```tsx
import { Scroll, AUTOSCROLL_TO } from '@design-system/scroll';

function LogView({ entries }) {
  return (
    <div style={{ height: 300 }}>
      <Scroll
        barHideStrategy='never'
        autoscrollTo='bottom'
      >
        {entries.map((e, i) => (
          <div key={i}>{e.text}</div>
        ))}
      </Scroll>
    </div>
  );
}
```

### Resize контейнера

Возможность изменять размер области по горизонтали, вертикали или в обе стороны. За угол тянется grip.

```tsx
import { Scroll, RESIZE } from '@design-system/scroll';

function ResizablePanel() {
  return (
    <div style={{ height: 400 }}>
      <Scroll resize='both'>
        <div>Resizable content — drag the corner to resize.</div>
      </Scroll>
    </div>
  );
}
```

### Событие скролла и инициализация

Колбэки `onScroll` и `onInitialized` для реакции на прокрутку и готовность скролла.

```tsx
import { Scroll } from '@design-system/scroll';

function Example() {
  return (
    <div style={{ height: 200 }}>
      <Scroll
        onScroll={(e) => console.log('scroll', e)}
        onInitialized={() => console.log('scroll ready')}
      >
        <div>Content</div>
      </Scroll>
    </div>
  );
}
```

## Accessibility

- OverlayScrollbars рендерит стандартную прокручиваемую область (viewport), контент остаётся в потоке документа и доступен скринридерам.
- Компонент принимает пропсы, проброшенные через `WithSupportProps`, в том числе стандартные HTML-атрибуты контейнера (например, `aria-*`) для кастомизации доступности.
- Для областей с автоскроллом (чаты, логи) убедитесь, что новые сообщения объявляются скринридеру (например, через `aria-live` на контейнере или объявлении обновлений).

## Best practices

1. **Задавайте высоту контейнеру** — у родителя `Scroll` должна быть явная высота (или размер через flex/grid), иначе прокрутка не появится.
2. **Автоскрол для потокового контента** — используйте `autoscrollTo="bottom"` или `autoscrollTo="right"` для логов и чатов; скролл к краю выполняется при маунте и при добавлении контента, если пользователь уже у края.
3. **Стратегия скрытия скроллбаров** — `barHideStrategy="leave"` по умолчанию уменьшает визуальный шум; для панелей настроек или таблиц можно использовать `barHideStrategy="never"`.
4. **CSP и nonce** — при строгой Content-Security-Policy используйте `setNonce(nonce)` из пакета перед первым рендером Scroll, чтобы разрешить инлайн-стили OverlayScrollbars.
