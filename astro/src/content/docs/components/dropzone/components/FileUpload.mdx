# FileUpload

Обёртка над кнопкой или другим элементом: клик открывает нативный диалог выбора файлов. Подходит для сценариев, когда нужна кнопка вместо видимой dropzone.

## Live examples

### Basic usage

<ExampleContainer>
  <ExampleRow gap="large" justifyContent="flex-start">

      <FileUpload onFilesUpload={() => {}}>

```tsx
import { FileUpload } from '@design-system/dropzone';

export function Example() {
  return (
```

```tsx
    </FileUpload>
  );
}
```

### Режимы и accept

- `mode="single"` — один файл
- `mode="multiple"` — несколько файлов (по умолчанию)
- `accept="image/*"` — только изображения

```tsx
import { FileUpload } from '@design-system/dropzone';

export function Example() {
  return (
    <FileUpload
      onFilesUpload={(files) => console.log(files)}
      mode="single"
      accept="image/*"
    >
      <button type="button">Выбрать изображение</button>
    </FileUpload>
  );
}
```

## Accessibility

- `children` должен быть доступен с клавиатуры (кнопка, ссылка или элемент с `tabIndex`).
- Скрытый `<input type="file">` не отображается в DOM.

## Best practices

1. **Один триггер** — передавайте один React-элемент в `children`.
2. **Обработка onClick** — FileUpload объединяет свой обработчик с `onClick` у `children`; при клике открывается диалог и вызывается `onClick` ребёнка.
3. **Типы файлов** — используйте `accept` для ограничения выбора.
