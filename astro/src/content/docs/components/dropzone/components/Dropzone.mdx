# Dropzone

Видимая область для загрузки файлов: перетаскивание файлов или клик по области открывает диалог выбора. Стили из design tokens.

### Режимы загрузки

- `mode="single"` — один файл
- `mode="multiple"` — несколько файлов (по умолчанию)

### Ограничение типов файлов

Используйте `accept` для фильтрации в диалоге выбора:

```tsx
import { Dropzone } from '@design-system/dropzone';

export function Example() {
  return (
    <Dropzone
      onFilesUpload={(files) => console.log(files)}
      accept="image/*"
    >
      <span>Только изображения</span>
    </Dropzone>
  );
}
```

## Accessibility

- Dropzone рендерится как `<button>`, доступен с клавиатуры.
- При `disabled` состояние корректно передаётся скринридерам.

## Best practices

1. **Понятный контент** — используйте `children` для пояснения: «Перетащите файлы сюда» или «Выберите файлы».
2. **Ограничение типов** — указывайте `accept` для фильтрации (например, `image/*`, `.pdf`).
3. **Режим** — `single` для одного файла; `multiple` для нескольких.
