# HiddenDropZone

Обёртка над произвольным контентом (форма, карточка). При перетаскивании файлов поверх области показывается overlay с dropzone. Подходит для форм, где загрузка не должна занимать место до момента drag.

### Контент overlay

Проп `content` — разметка, которая отображается в overlay при drag:

```tsx
<HiddenDropZone
  onFilesUpload={handleFiles}
  content={
    <>
      <h4>Загрузите вложения</h4>
      <div>Перетащите файлы на форму, чтобы прикрепить их</div>
    </>
  }
>
  {children}
</HiddenDropZone>
```

## Accessibility

- Overlay скрыт до момента drag; при перетаскивании файлов overlay отображается поверх контента.
- Dropzone внутри overlay доступен с клавиатуры.

## Best practices

1. **Понятный content** — overlay должен объяснять, что делать («Перетащите файлы сюда»).
2. **Размеры** — HiddenDropZone растягивается на весь `children`; `size` влияет на padding внутри overlay.
3. **Формы** — удобно оборачивать формы с полями ввода; при drag overlay не мешает видеть структуру формы.
