# Паттерны использования кнопок в layout

Рекомендации по правильному размещению и группировке кнопок в различных контекстах интерфейса.

## Основные принципы

### Группировка действий

Группируйте связанные действия вместе. Используйте визуальное разделение для разных типов действий:

```tsx
import { Button } from '@design-system/button';
import { Link } from '@design-system/link';

// ✅ Правильно: основные действия отдельно от вторичных
<div style={{ display: 'flex', gap: 12, justifyContent: 'flex-end' }}>
  <Link href="/cancel">Отмена</Link>
  <Button variant="secondary">Сохранить черновик</Button>
  <Button variant="primary">Опубликовать</Button>
</div>;
```

### Приоритет действий

Размещайте основное действие справа (для LTR интерфейсов). Вторичные действия — слева:

```tsx
// ✅ Правильно: основное действие справа
<div style={{ display: 'flex', gap: 12 }}>
  <Button variant="ghost">Отмена</Button>
  <Button variant="primary">Сохранить</Button>
</div>
```

### Модальные окна и диалоги

В модальных окнах размещайте кнопки в нижней части, выравнивая по правому краю:

```tsx
// ✅ Правильно: кнопки в footer модального окна
<footer
  style={{
    display: 'flex',
    gap: 12,
    justifyContent: 'flex-end',
    padding: '16px 24px',
    borderTop: '1px solid #e2e8f0',
  }}
>
  <Button variant="ghost">Отмена</Button>
  <Button variant="primary">Подтвердить</Button>
</footer>
```

## Примеры паттернов

### Формы

В формах размещайте кнопки действий внизу, после всех полей:

```tsx
<form>
  {/* Поля формы */}
  <div style={{ marginTop: 24, display: 'flex', gap: 12, justifyContent: 'flex-end' }}>
    <Button variant="ghost" type="button">
      Отмена
    </Button>
    <Button variant="primary" type="submit">
      Сохранить
    </Button>
  </div>
</form>
```

### Таблицы с действиями

Для действий над строками таблицы используйте IconButton:

```tsx
import { IconButton } from '@design-system/button';

// ✅ Правильно: компактные действия в таблице
<td>
  <div style={{ display: 'flex', gap: 8 }}>
    <IconButton icon="✏️" label="Редактировать" variant="ghost" />
    <IconButton icon="🗑️" label="Удалить" variant="ghost" />
  </div>
</td>;
```

### Панели инструментов

Группируйте связанные действия в панелях инструментов:

```tsx
// ✅ Правильно: логические группы действий
<div style={{ display: 'flex', gap: 16, padding: 12 }}>
  <div style={{ display: 'flex', gap: 8 }}>
    <IconButton icon="📝" label="Создать" variant="primary" />
    <IconButton icon="📋" label="Копировать" variant="secondary" />
  </div>
  <div style={{ width: 1, background: '#e2e8f0' }} />
  <div style={{ display: 'flex', gap: 8 }}>
    <IconButton icon="🔍" label="Поиск" variant="ghost" />
    <IconButton icon="⚙️" label="Настройки" variant="ghost" />
  </div>
</div>
```

## Доступность

- Используйте семантические HTML элементы (`<button>` для действий, `<a>` для навигации)
- Обеспечьте достаточный размер кликабельной области (минимум 44×44px)
- Группируйте связанные действия с помощью `role="group"` при необходимости
- Используйте `aria-label` для IconButton без текста
