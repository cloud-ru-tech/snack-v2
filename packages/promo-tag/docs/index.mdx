# Promo Tag

Компонент промо-тега. Поддерживает текст, внешний вид (appearance), роль (role: accent, decor), размеры (xs, s, m), контент до/после текста (beforeContent, afterContent) и опциональный клик (onClick — рендерит кнопку). Состояния задаются через data-атрибуты для стилизации.

**Version:** `{frontmatter.version}`

Поддерживает:

- **Appearance** — neutral, primary, red, orange, yellow, green, blue, violet, pink
- **Role** — accent (акцентный фон), decor (декоративный прозрачный)
- **Размеры** — xs, s, m
- **Контент** — beforeContent и afterContent (иконки, бейджи)
- **Клик** — при передаче onClick рендерится как `<button>`, иначе как `<div>`

## Overview

Promo Tag по умолчанию рендерит `<div>` с текстом и опциональным контентом до/после. При передаче `onClick` рендерится как `<button>` с state layer для hover/pressed. Внешний вид задаётся через `appearance` (цветовая палитра), `role` (accent — контрастный фон, decor — прозрачный декоративный) и `size` (xs, s, m). Для иконок и дополнительного контента используйте `beforeContent` и `afterContent`.

- **Appearance** — семантические цвета: primary для основных акций, red/orange для скидок, green для новинок и т.д.
- **Role** — accent для акцентных промо на карточках, decor для лёгких маркировок без фона.
- **Размер** — xs в карточках и списках, s/m для крупных блоков и баннеров.

## Usage

### Basic example

```tsx
import { PromoTag } from '@design-system/promo-tag';

export function Example() {
  return <PromoTag text='−20%' />;
}
```

### With appearance and size

```tsx
import { PromoTag } from '@design-system/promo-tag';

export function Example() {
  return <PromoTag text='Акция' appearance='primary' size='s' role='accent' />;
}
```

### Clickable tag

```tsx
import { PromoTag } from '@design-system/promo-tag';

export function Example() {
  return <PromoTag text='Подробнее об акции' onClick={() => window.open('/promo')} />;
}
```

### With before/after content

```tsx
import { PromoTag } from '@design-system/promo-tag';
import { SomeIcon } from '@design-system/icons';

<PromoTag text="Скидка" beforeContent={<SomeIcon />} />
<PromoTag text="Новинка" afterContent={<SomeIcon />} />
```

## Accessibility

- При рендере как `<div>` компонент носит декоративный характер; при рендере как `<button>` (с onClick) доступен фокус по Tab и активация по Enter/Space.
- State layer для кнопки помечен `aria-hidden`, чтобы не дублировать озвучивание.
- Семантика и контраст задаются через appearance/role и design tokens темы.

## Best practices

1. **Краткий текст** — используйте короткие подписи («−20%», «Акция», «Новинка»), чтобы тег не перегружал интерфейс.
2. **Выбор appearance** — primary для основных акций, цветные варианты — для семантики (скидка, новинка, ограниченное предложение).
3. **role** — accent для акцентных промо на контрастном фоне, decor для декоративных тегов с прозрачным фоном.
4. **Размер** — xs в карточках и списках, s/m для крупных блоков и баннеров.
5. **Клик** — передавайте onClick только когда тег ведёт к действию (открытие модалки, переход); иначе оставляйте статичный тег (рендер как div).
