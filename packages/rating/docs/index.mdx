# Rating

Компонент `Rating` отображает рейтинг в виде **звёзд**. Поддерживает **контролируемый и неконтролируемый** режимы (`value` / `defaultValue`), **настраиваемое количество звёзд** (`count`, по умолчанию 5), **половинчатые звёзды** (`allowHalf`), **сброс при повторном клике** (`allowClear`) и **режим только чтения** (`readonly`).

- **Количество звёзд**: `count` (по умолчанию 5).
- **Значение**: число от 0 до `count`; при `allowHalf` допустимы шаги 0.5 (например, 2.5).
- **Размеры**: `xs`, `s` (по умолчанию `s`).
- **Цветовые схемы** (`appearance`): primary, red, orange, yellow, green, blue, violet, pink (по умолчанию `yellow`).
- **Доступность**: каждая звезда — `role="radio"`, фокус по Tab, переключение по Enter/Space, `aria-checked`.

## Overview

Rating позволяет пользователям оценивать контент, товары или услуги с помощью визуального представления в виде звёзд. Состояние задаётся числом от 0 до количества звёзд; при включённом `allowHalf` можно выбирать половинки (например, 2.5 из 5).

Компонент:

- **Контролируемый / неконтролируемый**: управление через `value` + `onChange` или `defaultValue` (и опционально `onChange`).
- **Интерактивный**: клик по звезде (или по её половине при `allowHalf`) устанавливает значение; при `allowClear` повторный клик по текущей звезде сбрасывает рейтинг в 0.
- **Только чтение**: при `readonly` звёзды отображают значение без возможности изменения.
- **Клавиатура**: каждая звезда в фокусе переключается по Enter/Space; поддерживается навигация по Tab.
- **Кастомизация**: `count`, `size`, `appearance`, `className` и пропы из `WithSupportProps` (например, `data-test-id`).

## Usage

### Неконтролируемый рейтинг

```tsx
import { Rating } from '@design-system/rating';

export function Example() {
  return (
    <Rating
      count={5}
      defaultValue={3}
      allowHalf={false}
      allowClear
      onChange={(value) => console.log('Rating:', value)}
    />
  );
}
```

### Контролируемый рейтинг

```tsx

  const [value, setValue] = useState<number>(0);
```

## Props

Основные пропсы компонента:

| name | type | default | description |
|------|------|---------|-------------|
| count | `number` | 5 | Общее количество звёзд |
| value | `number` | — | Значение в контролируемом режиме (0 … count, при allowHalf — с шагом 0.5) |
| defaultValue | `number` | 0 | Начальное значение в неконтролируемом режиме |
| allowHalf | `boolean` | false | Разрешить половинчатые звёзды |
| allowClear | `boolean` | false | Сброс рейтинга при повторном клике по выбранной звезде |
| readonly | `boolean` | false | Режим только чтения |
| size | `'xs' \| 's'` | 's' | Размер звёзд |
| appearance | `Appearance` | 'yellow' | Цветовая схема (primary, red, orange, yellow, green, blue, violet, pink) |
| onChange | `(value: number) => void` | — | Колбек при смене значения |
| className | `string` | — | CSS-класс |

Компонент также поддерживает пропы из `WithSupportProps` (например, `data-test-id`).

## Accessibility

- Каждая звезда в интерактивном режиме имеет `role="radio"` и `aria-checked` в зависимости от заполнения.
- Фокус по Tab, переключение по Enter и Space по текущей звезде.
- В режиме `readonly` роль и tabIndex не задаются — компонент ведёт себя как статичное отображение рейтинга.

## Best practices

1. **Выбирайте контролируемый режим** при привязке к форме или API; используйте `defaultValue` для простого отображения с опциональным `onChange`.
2. **Используйте `allowHalf`** там, где нужна более тонкая градация (например, средние оценки).
3. **Включайте `allowClear`**, если по сценарию пользователь может снять оценку.
4. **Задавайте `readonly`** для отображения уже выставленного рейтинга без возможности редактирования.
5. **Добавляйте `data-test-id`** при необходимости стабильных автотестов.
