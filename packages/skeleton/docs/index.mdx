# Skeleton

Пакет компонентов для плейсхолдеров загрузки: **Skeleton** (блок произвольной формы), **SkeletonText** (строки текста) и **WithSkeleton** (обёртка для условного отображения скелетона или контента). Стили — из design tokens (Figma variables).

## Overview

Компоненты скелетонов показывают анимированные плейсхолдеры во время загрузки данных. В пакет входят:

- **Skeleton** — блок-плейсхолдер с настраиваемой шириной, высотой и скруглением. Подходит для картинок, карточек, аватаров.
- **SkeletonText** — строки-плейсхолдеры для текста. Поддержка `purpose`, `size`, `align` (типографика) и `lines` (количество строк).
- **WithSkeleton** — обёртка: при `loading={true}` показывает произвольный JSX-скелетон, при `loading={false}` — `children`.
- **Стили** — отступы, анимация, цвета из design tokens.
