# InfoRow

`InfoRow` показывает одну или две пары "метка - значение" в строке. Компонент подходит для кратких сводок в карточках, сайдбарах и деталках сущностей.

Поддерживаются:
- одна колонка (`column="1"`);
- две колонки в одной строке (`column="2"`);
- разделители, скелетон, tooltip к метке;
- действия справа (`rowActions`, `secondaryRowActions`);
- обрезка длинных заголовков через `labelTruncate`.

Если нужно отрисовать несколько строк по данным, используйте `useGetContent` и `InfoRowFieldItem` (пример ниже).

## Когда использовать

- Короткая сводка полей "ключ - значение" в карточке или панели.
- Детальная страница объекта, где важна компактная подача.
- Когда таблица избыточна, а данных немного.

## Когда лучше выбрать другой компонент

- `InfoGroup` - когда данные уже описаны схемой полей и нужно вывести список строк по объекту.
- `MobileInfoRow` - когда нужен мобильный вертикальный формат строки.
- `AdaptiveInfoRow` - когда нужно переключение desktop/mobile по `layoutType`.

## Доступность

- Разделители: `role="separator"`.
- Для иконок в `rowActions` добавляйте `aria-label`.
- Кнопки наследуют поведение и доступность `@ds/button`.
- `QuestionTooltip`: кнопка-триггер с `aria-label`.
