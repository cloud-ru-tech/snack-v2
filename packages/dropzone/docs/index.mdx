# Dropzone

Пакет `@ds/dropzone` предоставляет три компонента для загрузки файлов через drag-n-drop и клик:

- [**Dropzone**](/components/dropzone/dropzone) — видимая зона для перетаскивания и клика. Три размера `s/m/l`, режимы `single/multiple`, состояние `disabled`.
- [**FileUpload**](/components/dropzone/file-upload) — обёртка над произвольным триггером (например, кнопкой), открывающая нативный диалог выбора файлов. Без визуальной зоны.
- [**HiddenDropZone**](/components/dropzone/hidden-drop-zone) — скрытая оверлей-зона, накрывающая произвольный контент (форму, карточку) при перетаскивании файлов.

## Установка

```bash
pnpm add @ds/dropzone
```

```ts
import { Dropzone, FileUpload, HiddenDropZone } from '@ds/dropzone'
import '@ds/dropzone/style.css'
```

## Когда какой использовать

| Задача | Компонент |
|--------|-----------|
| Явная зона для перетаскивания файлов на странице | `Dropzone` |
| Кнопка «Загрузить» без отдельной зоны | `FileUpload` |
| Прикрепить файл к существующей форме / карточке drag-n-drop | `HiddenDropZone` |

## Общие принципы

- **Режим `single` или `multiple`.** Выбирайте по сценарию: аватарка и подпись — `single`, прикрепления к письму — `multiple`.
- **Ограничивайте типы через `accept`.** Пользователь видит фильтр в системном диалоге и понимает, что ожидается.
- **Дублируйте сценарий drag-n-drop клавиатурно-доступным триггером.** Drag-n-drop недоступен с клавиатуры и скринридером — используйте `FileUpload` рядом или внутри `Dropzone`.
