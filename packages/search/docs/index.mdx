# Search

Публичный компонент поля поиска для интерфейсов design system. Содержит **SearchPrivate** (иконка, ввод, очистка, загрузка, `onSubmit` по Enter) внутри оболочки с **акриловым фоном**, границей и слоем фокуса. Опционально справа от поля можно вывести **ButtonField** (действие + шеврон списка) с вертикальным разделителем.

**Version:** `{frontmatter.version}`

Поверх возможностей SearchPrivate компонент добавляет:

- **Визуальная оболочка** — фон (`background`), реакция на hover и `:focus-visible` на уровне материала
- **Слот справа** — `buttonField` с `action`, `onClick`, опциями `loading`, `disabled`, `withDropdownList`
- **Разделитель** — `outline` между полем и слотом (по умолчанию включён, если задан `buttonField`)
- **Согласованное отключение** — при `disabled` на Search дополнительно блокируется и postfix-кнопка, если передан собственный `buttonField.disabled`, он объединяется с состоянием поля

## Overview

**Search** — обёртка над **SearchPrivate** с корневым контейнером (`data-size`, `data-loading`, `data-disabled`, `data-withbackground`, `data-focusvisible`). `ref` пробрасывается на **нативный `<input>`** внутри SearchPrivate (как и у SearchPrivate).

Поведение ввода, очистки, клавиатуры и `onSubmit` совпадает с компонентом **Search Private** (`@design-system/search-private`): Enter с непустым значением вызывает `onSubmit(value)`; навигация по постфиксу (кнопка очистки) учитывается внутри SearchPrivate.

Пропсы поддержки разметки и тестов (`WithSupportProps`, в т.ч. `data-test-id`) передаются во внутренний контейнер SearchPrivate через `extractSupportProps`.

## Usage

### Базовый пример (uncontrolled)

```tsx
import { Search } from '@design-system/search';

export function Example() {
  return <Search placeholder="Поиск" />;
}
```

### Управляемое значение

```tsx
import { Search } from '@design-system/search';
import { useState } from 'react';

export function Example() {
  const [value, setValue] = useState('');
  return (
    <Search
      value={value}
      onChange={setValue}
      placeholder="Введите запрос"
    />
  );
}
```

### Подтверждение поиска и слот справа

```tsx
import { PlaceholderSVG } from '@design-system/icons';
import { Search, SIZE } from '@design-system/search';

export function Example() {
  return (
    <Search
      size={SIZE.M}
      placeholder="Поиск"
      onSubmit={(query) => {
        // интеграция с поиском или навигацией (query)
      }}
      buttonField={{
        size: SIZE.M,
        action: <PlaceholderSVG size={24} />,
        onClick: () => {},
        withDropdownList: true,
      }}
    />
  );
}
```

### Без разделителя между полем и кнопкой

```tsx
import { Search } from '@design-system/search';

export function Example() {
  return (
    <Search
      outline={false}
      buttonField={{
        action: <span>⋯</span>,
        onClick: () => {},
      }}
    />
  );
}
```

## Accessibility

- Фокус и ввод относятся к **нативному полю** (`type="text"`, по умолчанию `inputMode="search"` у SearchPrivate); `ref` ведёт на этот input.
- Кнопка **очистки** и навигация с клавиатуры реализованы в SearchPrivate (в т.ч. переход к постфиксу и подтверждение по Enter при непустом значении).
- При `disabled` поле и postfix-кнопка (если есть) недоступны для взаимодействия; визуально отражается через `data-disabled` на оболочке и внутреннем контейнере SearchPrivate.
- Для автотестов и стабильных селекторов используйте проп **`data-test-id`** (и другие атрибуты из `WithSupportProps`), как описано в документации Search Private.

## Best practices

1. **Семантика поиска** — для мобильных клавиатур оставляйте `inputMode` в режиме поиска (значение по умолчанию в SearchPrivate), если сценарий именно строка запроса.
2. **Слот справа** — передавайте в `buttonField.action` готовый узел (иконку фильтра, аватар и т.д.); `onClick` обязателен, даже если список открывается снаружи — свяжите его с вашим меню или стором.
3. **Загрузка** — при `loading={true}` иконка поиска заменяется индикатором; не смешивайте с активным вводом без необходимости: лучше блокировать поле через `disabled`, если ввод недопустим.
4. **Низкоуровневые сценарии** — если не нужны акрил, Divider и ButtonField, рассмотрите использование только **SearchPrivate** для более лёгкой вёрстки.
