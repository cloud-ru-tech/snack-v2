# Dropdown

Компонент выпадающего контейнера (dropdown), построенный на базе **PopoverPrivate**. Отображает произвольный контент в поповере относительно триггера (кнопки, иконки и т.д.), поддерживает открытие по клику, ховеру или фокусу, встроенные состояния загрузки и ошибок.

## Overview

**Dropdown** — обёртка над PopoverPrivate с фиксированными настройками под типичный сценарий выпадающего блока: без стрелки, с контейнером под контент и опциональными состояниями (loading, not-found, no-data, data-error).

Компонент автоматически обеспечивает:

- **Триггеры** — открытие по клику (`click`), ховеру (`hover`), фокусу (`focus` / `focusVisible`) или комбинациям (`hoverAndFocus`, `clickAndFocusVisible` и др.).
- **Позиционирование** — размещение поповера относительно триггера (`placement`: `bottom-start`, `top-end` и т.д.) с цепочкой запасных позиций (`fallbackPlacements`).
- **Ширина** — стратегия `widthStrategy`: `auto`, `gte` (не уже триггера), `eq` (строго по ширине триггера). По умолчанию `gte`.
- **Состояния** — встроенные экраны загрузки (спиннер), «Не найдено», «Нет данных», «Ошибка» с опциональной кнопкой действия (локализуются через `@design-system/locale`).
- **Доступность** — закрытие по Escape, клик вне, поддержка `triggerRef` для кастомного триггера.

## Usage

### Базовый пример

```tsx
import { Button } from '@design-system/button';
import { Dropdown } from '@design-system/dropdown';

export function Example() {
  return (
    <Dropdown content={<div>Контент поповера</div>}>
      <Button label="Открыть" view="filled" />
    </Dropdown>
  );
}
```

### Управление открытием (controlled)

```tsx
import { Button } from '@design-system/button';
import { Dropdown } from '@design-system/dropdown';
import { useState } from 'react';

export function Example() {
  const [open, setOpen] = useState(false);
  return (
    <Dropdown
      content={<div>Контент</div>}
      open={open}
      onOpenChange={setOpen}
    >
      <Button label={open ? 'Закрыть' : 'Открыть'} view="filled" />
    </Dropdown>
  );
}
```

### Триггер по ref (без children)

```tsx
import { Button } from '@design-system/button';
import { Dropdown } from '@design-system/dropdown';
import { useRef } from 'react';

export function Example() {
  const buttonRef = useRef(null);
  return (
    <>
      <Dropdown content={<div>Контент</div>} triggerRef={buttonRef} />
      <Button innerRef={buttonRef} label="Триггер" view="filled" />
    </>
  );
}
```

### Состояния: загрузка, нет данных, ошибка

Компонент принимает проп `state` типа `DropdownState`. При переданном состоянии вместо `content` отображается соответствующий экран (спиннер, InfoBlock с текстом и опциональной кнопкой «Перезагрузить»). Тексты по умолчанию берутся из локали (`@design-system/locale`), при необходимости можно переопределить `description`, `actionLabel`, `onActionClick`, для состояний с иконкой — `icon`.

Типы состояний: `'loading'`, `'not-found'`, `'no-data'`, `'data-error'`.

```tsx
import { Button } from '@design-system/button';
import { Dropdown } from '@design-system/dropdown';
import { useRef } from 'react';

function Example() {
  const ref = useRef(null);

  // Загрузка — показывается спиннер
  return (
    <Dropdown state={{ type: 'loading' }} triggerRef={ref}>
      <Button innerRef={ref} label="Загрузка" view="filled" />
    </Dropdown>
  );
}

// Нет данных + кнопка действия
function NoDataExample() {
  const ref = useRef(null);
  return (
    <Dropdown
      content={null}
      state={{
        type: 'no-data',
        description: 'Список пуст',
        actionLabel: 'Обновить',
        onActionClick: () => fetchData(),
      }}
      triggerRef={ref}
    >
      <Button innerRef={ref} label="Нет данных" view="filled" />
    </Dropdown>
  );
}
```

## Accessibility

- Поведение наследуется от **PopoverPrivate**: корректное управление фокусом, закрытие по Escape, поддержка открытия по клавишам Enter/Space при `trigger="click"`.
- Для кастомного триггера передавайте `triggerRef` и сохраняйте доступность кнопки/контрола (доступ с клавиатуры, `aria-expanded` при необходимости).
- Встроенные состояния (loading, not-found, no-data, data-error) используют компонент **InfoBlock** и кнопки **ButtonGroup** с учётом доступности.

## Best practices

1. **Триггер** — используйте явный элемент управления (кнопку, иконку). Для кнопки без обёртки передавайте `triggerRef` и `innerRef` на кнопку.
2. **Ширина** — по умолчанию `widthStrategy="gte"` обеспечивает ширину поповера не меньше триггера; для узких списков опций этого обычно достаточно.
3. **Состояния** — при асинхронной загрузке контента передавайте `state={{ type: 'loading' }}`, после загрузки — `state={undefined}` и актуальный `content`. Для пустых выборок или ошибок используйте `'no-data'` / `'data-error'` с опциональным `onActionClick`.
4. **Локализация** — тексты состояний задаются в `@design-system/locale` (ключи `Dropdown.states.*`); при кастомных описаниях передавайте `description` и `actionLabel` в объекте `state`.
