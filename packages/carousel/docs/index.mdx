# Carousel

Горизонтальная карусель дизайн-системы: в окне просмотра показывается одно или несколько слайдов, перелистывание — стрелками, свайпом и полоской пагинации (`PaginationSlider` из `@design-system/pagination`). Поддерживаются дробный `showItems` («peek»), контролируемое состояние страницы, зацикливание и автопрокрутка при `infiniteScroll`. Верстка и отступы завязаны на токены (в том числе `gap` по умолчанию из переменных размерности).

## Overview

**Carousel** — компонент для набора слайдов, переданных как **`children`**: массив React-элементов (по одному элементу на слайд). Стрелки и блок пагинации можно отключить пропами `arrows` и `pagination`.

Компонент обеспечивает:

- **Несколько слайдов в окне** — `showItems` задаёт, сколько элементов видно одновременно; допускаются дробные значения для эффекта «часть следующего слайда».
- **Шаг прокрутки** — `scrollBy` определяет, на сколько позиций сдвигать при переходе (по умолчанию — `Math.trunc(showItems)`).
- **Навигация** — стрелки, свайп (`swipe`), полоска страниц снизу (`pagination`); видимость стрелок — `controlsVisibility`: по ховеру или всегда.
- **Управление состоянием** — внутренний индекс страницы или контролируемый режим через `state={{ page, onChange }}` (индекс страницы в API — с нуля).
- **Цикл и автоплей** — `infiniteScroll` и опциональный `autoSwipe` (интервал в секундах); автопрокрутка в реализации согласована с бесконечным режимом.

Тип пропсов расширен утилитой `WithSupportProps` из `@design-system/utils`: допускаются `data-test-id` и стандартные `aria-*`.

## Accessibility

- Через поддерживаемые пропсы можно передавать **`aria-*`** для подписей региона и кнопок навигации там, где это нужно по сценарию.
- Учитывайте **таб-ордер** на слайдах, которые частично или полностью скрыты: интерактивный фокус не должен «теряться» на невидимых страницах.
- **Автопрокрутка** (`autoSwipe`) не должна быть единственным способом получить контент: оставляйте ручное управление стрелками/пагинацией и возможность остановить автоплей, если продуктовые требования это допускают.

## Best practices

1. **Один корневой элемент на слайд** — каждый child лучше оборачивать в предсказуемый контейнер (`article`, `div`, карточку), чтобы разметка и поведение фокуса были стабильными.
2. **Синхронизация с внешним состоянием** — для URL, табов или аналитики используйте `state` с `page` и `onChange`; при отображении страниц в UI помните о расхождении 0-based API и 1-based пагинации внутри реализации.
3. **Пара `showItems` и `scrollBy`** — подбирайте так, чтобы на последнем шаге не оставалось пустого «хвоста»; при дробном `showItems` ширина элемента считается от полного значения, видимость по фокусу — с учётом `Math.trunc(showItems)`.
4. **Автоплей** — включайте `autoSwipe` осознанно и в связке с `infiniteScroll`, как задумано в компоненте; оценивайте влияние на доступность и отвлекаемость.
5. **Тесты** — используйте `data-test-id` из поддерживаемых пропсов для устойчивых селекторов в e2e.
