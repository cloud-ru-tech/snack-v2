# AlertTop

Полноширинный алерт для области под шапкой: фон и типографика зависят от **`appearance`**, кнопки в стиле **onAccent**. Обводки (`outline`) нет — компонент рассчитан на контрастный баннер.

## Usage

### Базовый пример

```tsx
import { AlertTop, APPEARANCE, SIZE } from '@design-system/alert';

export function Example() {
  return (
    <AlertTop
      appearance={APPEARANCE.Warning}
      size={SIZE.M}
      title='Технические работы'
      description='Возможны кратковременные сбои.'
    />
  );
}
```

### С действиями

```tsx
import { AlertTop, APPEARANCE, SIZE } from '@design-system/alert';

export function Example() {
  return (
    <AlertTop
      appearance={APPEARANCE.Info}
      size={SIZE.S}
      title='Новая функция'
      description='Смотрите раздел «Настройки».'
      actions={{
        primary: { label: 'Перейти', onClick: () => {} },
      }}
    />
  );
}
```

## Accessibility

- Корень с **`role="alert"`**.
- Обеспечивайте достаточный контраст текста и иконок на акцентном фоне выбранного `appearance` (токены темы).

## Best practices

1. **Одно сообщение на полосу** — не перегружайте баннер вторичным текстом; вынесите детали на страницу или в модалку.
2. **Neutral vs semantic** — neutral для общих объявлений; error / warning / success / info — когда важна быстрая семантическая оценка ситуации.
3. **Закрытие** — передавайте `onClose`, если баннер не критичен и пользователь может его скрыть; не дублируйте то же действие основной кнопкой без причины.
4. **Ширина** — компонент рассчитан на контейнер на всю ширину области контента; в узких превью в документации используйте обёртку с `max-width` для читаемости.
