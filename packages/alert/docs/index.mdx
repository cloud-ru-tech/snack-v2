# Alert

Пакет `@ds/alert` предоставляет два варианта уведомлений:

- [**Alert**](/components/alert/alert) — inline-алерт внутри страницы: в форме, в карточке, в списке. Поддерживает actions, close-кнопку и режим сворачивания.
- [**AlertTop**](/components/alert/alert-top) — системный баннер, который крепится к верхней кромке страницы. Всегда на сплошной цветной подложке.

## Установка

```bash
pnpm add @ds/alert
```

```ts
import { Alert, AlertTop } from '@ds/alert'
```
