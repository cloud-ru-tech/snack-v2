# Alert

Пакет содержит **Alert** (встраиваемое сообщение в контенте с опциональной обводкой) и **AlertTop** (полноширинный баннер под шапкой). Оба разделяют общую разметку и пропсы (кроме `outline`, только у `Alert`).

**Version:** `{frontmatter.version}`

## Installation

```bash
npm install @design-system/alert
# or
yarn add @design-system/alert
# or
pnpm add @design-system/alert
```

## Overview

- **Alert** — `variant="inline"`: фон и иконка по `appearance`, опционально `outline`, роль `alert`. Подходит для форм, карточек, модалок.
- **AlertTop** — `variant="top"`: акцентный фон по `appearance`, типичное использование — полоса под хедером приложения.
- Общие возможности: `title`, `description`, `actions` (primary / secondary), `onClose`, `align` (vertical | horizontal), `collapsible`, размеры `s` | `m`, константы `APPEARANCE`, `SIZE`, `ALIGN` для типизации.
