# Changelog

All notable changes to `@design-system/avatar` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-01-15

### Added

- Initial release of Avatar component
- Support for user images with automatic fallback to initials
- Initials generation from user names (1 or 2 characters)
- Multiple size options: `xs`, `s`, `m`, `xl`, `3xl`, `6xl`, `10xl`
- Two shape options: `round` (default) and `square`
- Nine color schemes: `neutral`, `primary`, `red`, `orange`, `yellow`, `green`, `blue`, `violet`, `pink`
- `showTwoSymbols` prop for displaying two characters instead of one
- Full TypeScript support with proper type definitions
- Accessibility features: proper ARIA attributes, keyboard navigation
- Automatic image error handling with fallback to initials

### Documentation

- Complete component documentation with examples
- Storybook stories for all variants and sizes
- Usage examples and API reference
- Best practices and use cases
