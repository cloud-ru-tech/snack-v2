# Stepper

Пакет `@ds/stepper` предоставляет индикатор прогресса для многошаговых сценариев. Все варианты используют единый render-prop API и общую модель состояний шагов.

- [**Stepper**](/components/stepper/stepper) — десктопный горизонтальный индикатор шагов.
- [**MobileStepper**](/components/stepper/mobile-stepper) — компактный индикатор для мобильных экранов.
- [**AdaptiveStepper**](/components/stepper/adaptive-stepper) — автоматически переключается между desktop и mobile по viewport.

## Установка

```bash
pnpm add @ds/stepper
```

```ts
import { Stepper, MobileStepper, AdaptiveStepper } from '@ds/stepper'
```
