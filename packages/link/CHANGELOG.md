# Changelog

All notable changes to `@design-system/link` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-01-15

### Added

- Initial release of Link component
- Support for internal and external links
- Automatic external link detection with security attributes
- Full TypeScript support with proper type definitions
- Accessibility features: proper ARIA attributes, keyboard navigation

### Dependencies

- Based on `@snack-uikit/link@0.17.15`

### Documentation

- Complete component documentation with examples
- Storybook stories for all variants
- Usage examples and API reference

## [Unreleased]

### Planned

- Link variants (primary, secondary)
- Icon support
- Custom styling options
- Link group component
