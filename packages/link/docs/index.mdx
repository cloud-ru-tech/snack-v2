# Link

Компонент стилизованной ссылки для использования в интерфейсе и внутри текста. Поддерживает разные варианты внешнего вида (appearance), роли (role), обрезку длинного текста и полиморфный рендер через `as` (например, для роутеров).

**Version:** `{frontmatter.version}`

Поддерживает:
- **Роли** — `regular`, `onAccent` — для размещения на обычном фоне или на акцентной поверхности
- **Внешний вид** — neutral, invertNeutral, primary, red, orange, yellow, green, blue, violet, pink — для контраста с фоном
- **Подчёркивание** — `underlined={true}` для отображения ссылки с нижним подчёркиванием (по умолчанию без подчёркивания)
- **Внутри текста** — `insideText={true}` для ссылки в абзаце с переносами; иначе текст обрезается с настраиваемым вариантом (`truncateVariant: 'end' | 'middle'`)
- **Полиморфный компонент** — `as` для рендера в виде другого элемента или компонента (например, `Link as={ReactRouterLink} to="/path" />`)
- **Безопасность** — при `target="_blank"` автоматически добавляется `rel="noopener noreferrer"`
- Figma: [Link](https://www.figma.com/design/aNPU3MHwRJiEwbk5F82zux/Snack-Ui-Kit-variables?node-id=6913-5372&p=f&m=dev)

## Overview

Link рендерит по умолчанию семантичный `<a>`, расширяемый атрибутами `href`, `target`, `onClick` и др. Через проп `as` можно передать другой компонент или тег — тогда он получит стили ссылки и пропы `data-role`, `data-appearance`, `data-inside-text`. Текст отображается через `TruncateString` (одна строка, вариант обрезки по желанию) или без обрезки при `insideText={true}`.

- **Роль** — `regular` (по умолчанию) или `onAccent` для размещения на акцентном фоне
- **Appearance** — цветовая схема ссылки (по умолчанию `primary`)
- **underlined** — наличие нижнего подчёркивания (по умолчанию `false`)
- **insideText** — ссылка внутри абзаца, с переносами
- **truncateVariant** — при длинном тексте вне абзаца: `end` или `middle`

## Usage

### Basic example

```tsx
import { Link } from '@design-system/link';

export function Example() {
  return <Link text="Перейти" href="https://example.com" />;
}
```

По умолчанию используются `role="regular"`, `appearance="primary"`, для `<a>` — `target="_blank"` и `href="#"` при отсутствии `href`.

### With role and appearance

```tsx
import { Link, APPEARANCE, ROLE } from '@design-system/link';

export function Example() {
  return (
    <Link
      text="Ссылка на акценте"
      href="/path"
      role={ROLE.OnAccent}
      appearance={APPEARANCE.Primary}
    />
  );
}
```

### Underlined

```tsx
import { Link } from '@design-system/link';

export function Example() {
  return <Link text="Подчёркнутая ссылка" href="#" underlined />;
}
```

### Inside text

```tsx
import { Link } from '@design-system/link';

export function Article() {
  return (
    <p>
      Подробнее смотрите в <Link text="документации" href="/docs" insideText /> и на странице
      обновлений.
    </p>
  );
}
```

### Truncate long text

```tsx
import { Link } from '@design-system/link';

export function Example() {
  return (
    <Link
      text="Очень длинный текст ссылки, который не помещается в одну строку"
      href="#"
      truncateVariant="middle"
    />
  );
}
```

### Polymorphic (e.g. React Router)

```tsx
import { Link } from '@design-system/link';
import { Link as RouterLink } from 'react-router-dom';

export function Nav() {
  return (
    <Link as={RouterLink} to="/dashboard" text="В кабинет" />
  );
}
```

Переданный компонент должен принимать `className`, `data-role`, `data-appearance`, `data-inside-text`, `data-underlined` и остальные проброшенные пропы.

При рендере как `<a>` (по умолчанию) компонент также принимает нативные атрибуты якоря: `href`, `target`, `download`, `onClick` и т.д. Поддерживаются `data-test-id` и `aria-*` через WithSupportProps. При `as` передаются все пропы, кроме описанных выше, переданному компоненту.

## Accessibility

- При рендере как `<a>` сохраняется семантика ссылки; скринридеры объявляют элемент как ссылку.
- Для ссылок без понятного контекста используйте `aria-label` или убедитесь, что текст ссылки осмыслен («Подробнее», «Перейти в раздел X»).
- При `target="_blank"` автоматически выставляется `rel="noopener noreferrer"`.
- Компонент принимает стандартные HTML-атрибуты и поддержку `data-test-id` и `aria-*` для тестов и доступности.

## Best practices

1. **Текст ссылки** — используйте осмысленный текст вместо «здесь» или «подробнее» без контекста.
2. **Appearance и фон** — подбирайте `appearance` под фон (neutral/primary на светлом, onAccent на акцентном блоке).
3. **Внутри текста** — для ссылок в абзаце задавайте `insideText={true}`.
4. **Длинный текст** — при ограниченной ширине используйте `truncateVariant="end"` или `"middle"`.
5. **Роутеры** — для SPA-навигации используйте `as={RouterLink}` (или аналог) с пропом `to` вместо `href`.
6. **Внешние ссылки** — оставляйте `target="_blank"` по умолчанию или явно; `rel="noopener noreferrer"` выставляется автоматически.
