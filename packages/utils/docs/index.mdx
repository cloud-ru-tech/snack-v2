## useThemeConfig

Возвращает текущую тему, CSS-класс из `themeMap` и функцию переключения `changeTheme`.

```tsx
import { useThemeConfig } from '@design-system/utils';

const themeMap = { light: 'sn-light', dark: 'sn-dark' };

function Example() {
  const theme = useThemeConfig({ themeMap, defaultTheme: 'light' });
  return (
    <div className={theme.themeClassName}>
      <button onClick={() => theme.changeTheme('dark')}>Тёмная тема</button>
    </div>
  );
}
```

## ThemeProvider и useThemeContext

**ThemeProvider** — провайдер темы по `themeMap` и `defaultTheme`. **useThemeContext** — доступ к текущей теме и `changeTheme` из контекста.

```tsx
import { ThemeProvider, useThemeContext } from '@design-system/utils';

const themeMap = { light: 'sn-light', dark: 'sn-dark' };

function ThemedContent() {
  const { theme, themeClassName, changeTheme } = useThemeContext();
  return <div className={themeClassName}>Тема: {theme}</div>;
}

function App() {
  return (
    <ThemeProvider themeMap={themeMap} defaultTheme="light">
      <ThemedContent />
    </ThemeProvider>
  );
}
```

## useValueControl

Поддержка controlled/uncontrolled: один интерфейс для `value`/`defaultValue` и `onChange`.

```tsx
import { useValueControl } from '@design-system/utils';

function Toggle({ value, defaultValue, onChange }) {
  const [open, setOpen] = useValueControl({ value, defaultValue, onChange });
  return <button onClick={() => setOpen(!open)}>{open ? 'Закрыть' : 'Открыть'}</button>;
}
```

## useDebounce

Возвращает стабильный коллбек, который вызывается с задержкой после последнего вызова.

```tsx
import { useDebounce } from '@design-system/utils';

function Search() {
  const handleSearch = useDebounce(() => {
    console.log('Поиск по запросу...');
  }, 300);
  return <input onChange={handleSearch} />;
}
```

## useEventHandler

Возвращает обработчик с неизменной ссылкой: внутри всегда вызывается актуальная функция, без лишних ре-рендеров дочерних компонентов.

```tsx
import { useEventHandler } from '@design-system/utils';

function List({ items, onItemClick }) {
  const handleClick = useEventHandler(onItemClick);
  return items.map((item) => <div key={item.id} onClick={handleClick}>{item.name}</div>);
}
```

## useLayoutEffect (SSR-безопасный)

Из пакета экспортируется `useLayoutEffect`: в браузере это обычный useLayoutEffect, в SSR — useEffect. Используйте вместо React.useLayoutEffect для совместимости с SSR.

```tsx
import { useRef } from 'react';
import { useLayoutEffect } from '@design-system/utils';

function Measure() {
  const ref = useRef(null);
  useLayoutEffect(() => {
    if (ref.current) console.log(ref.current.getBoundingClientRect());
  }, []);
  return <div ref={ref}>...</div>;
}
```

## useDynamicList

Делит список на видимые и скрытые элементы по ширине контейнера (например, табы + «ещё»).

```tsx
import { useRef } from 'react';
import { useDynamicList } from '@design-system/utils';

function Tabs({ items }) {
  const containerRef = useRef(null);
  const { visibleItems, hiddenItems } = useDynamicList({
    items,
    parentContainerRef: containerRef,
    maxVisibleItems: 5,
  });
  return (
    <div ref={containerRef}>
      {visibleItems.map((item) => <span key={item.id}>{item.label}</span>)}
      {hiddenItems.length > 0 && <Dropdown items={hiddenItems} />}
    </div>
  );
}
```

## useSwipeable

Обработка свайпов (на базе react-swipeable): коллбеки по направлениям, ограничение направлений, атрибут `data-swipe-directions` для вложенных областей.

```tsx
import { useSwipeable } from '@design-system/utils';

function SwipeCard() {
  const handlers = useSwipeable({
    onSwipedLeft: () => console.log('свайп влево'),
    onSwipedRight: () => console.log('свайп вправо'),
    availableDirections: ['LEFT', 'RIGHT'],
  });
  return <div {...handlers}>Свайпни меня</div>;
}
```

## useModalOpenState

Подключает к модалке закрытие по кнопке «Назад» (popstate) и по CloseWatcher (Escape/жест).

```tsx
import { useModalOpenState } from '@design-system/utils';

function Modal({ open, onClose }) {
  useModalOpenState(open, onClose, {
    closeOnPopstate: true,
    closeByCloseWatcher: true,
  });
  return open ? <div role="dialog">...</div> : null;
}
```

## usePopstateSubscription

Подписка на событие `popstate` (навигация назад/вперёд). Второй аргумент — включить/выключить подписку.

```tsx
import { usePopstateSubscription } from '@design-system/utils';

function SyncWithHistory() {
  usePopstateSubscription((e) => {
    console.log('Навигация назад/вперёд', e.state);
  }, true);
  return null;
}
```

## useDataPersist

Чтение и запись состояния в localStorage и в query-параметрах URL. Использует `options` (queryKey, localStorageKey, validateData) и опционально parser/serializer. Источники: **LocalStorageSource**, **QueryParamSource**, базовый **BaseSource**.

```tsx
import { useState } from 'react';
import { useDataPersist } from '@design-system/utils';

const options = {
  queryKey: 'filter',
  localStorageKey: 'my-filter',
  validateData: (v): v is { query: string } => typeof v?.query === 'string',
};

function FilterState() {
  const { getDefaultData, setDataToStorages } = useDataPersist({ options });
  const [filter, setFilter] = useState(getDefaultData ?? { query: '' });
  const save = () => setDataToStorages(filter);
  return <input value={filter.query} onChange={(e) => setFilter({ query: e.target.value })} />;
}
```

## excludeSupportProps

Удаляет из объекта пропов все `data-test-*` и `aria-*`, чтобы не пробрасывать их в DOM.

```tsx
import { excludeSupportProps, extractSupportProps, extractDataTestProps } from '@design-system/utils';

const props = {
  'data-test-id': 'submit-btn',
  'aria-label': 'Отправить',
  onClick: () => {},
  className: 'btn',
};

const restProps = excludeSupportProps(props);
// { onClick, className } — передать в DOM-элемент
```

## extractSupportProps

Оставляет в объекте только пропы `data-test-*` и `aria-*` (для обёртки или тестов).

```tsx
const supportProps = extractSupportProps(props);
// { 'data-test-id', 'aria-label' }
```

## extractDataTestProps

Оставляет только пропы с префиксом `data-test-*`.

```tsx
const dataTestProps = extractDataTestProps(props);
// { 'data-test-id', 'data-test-name' }
```

## isBrowser

Проверка окружения: `true` в браузере, `false` при SSR. Используйте перед обращением к `window` или `document`.

```tsx
import { isBrowser } from '@design-system/utils';

if (isBrowser()) {
  window.addEventListener('resize', handler);
}
```

## ValueOf

Тип-утилита: union всех значений объекта.

```tsx
import type { ValueOf } from '@design-system/utils';

const sizes = { sm: 'small', md: 'medium', lg: 'large' } as const;
type Size = ValueOf<typeof sizes>; // 'small' | 'medium' | 'large'
```

## WithSupportProps

Тип для пропов компонента с поддержкой `data-test-id` и AriaAttributes.

```tsx
import type { WithSupportProps } from '@design-system/utils';

type ButtonProps = WithSupportProps<{
  label: string;
  variant: 'primary' | 'secondary';
}>;
```

## Best practices

1. **useIsomorphicLayoutEffect** вместо useLayoutEffect для SSR.
2. **excludeSupportProps** — перед передачей пропов в DOM; **extractSupportProps** — для обёртки (data-test-id, aria-*).
3. **useValueControl** — для компонентов с controlled/uncontrolled режимом.
4. **useModalOpenState** — закрытие по истории (popstate) и CloseWatcher.
