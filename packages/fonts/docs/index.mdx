# Fonts

`@ds/fonts` — служебный пакет без runtime-кода. Содержит `@font-face`-декларации семейств SB Sans (woff2/woff), а также Inter и Roboto Mono (variable woff2). Подключается **один раз** на корневом уровне приложения; компоненты дизайн-системы дальше ссылаются на эти семейства через токены типографики.

## Когда использовать

- Хост-приложение использует компоненты `@ds/*` и хочет получить тот же типографический стек, что в Storybook и docs.
- Нужны веса и начертания SB Sans, которые используют токены типографики, — пакет регистрирует их все.

## Установка

```bash
pnpm add @ds/fonts
```

### Через SCSS (рекомендовано)

```scss
@use '@ds/fonts/scss';
```

### Через CSS

```ts
import '@ds/fonts/css'
```

Подключение работает в любой современной сборке: SCSS-импорт даёт инкрементальные пересборки, CSS-вариант — статический файл для no-bundler сценариев.

## Анатомия

### Семейства

Файлы лежат в `packages/fonts/fonts/`, каждое начертание — отдельный `@font-face` с `font-display: swap`.

| Семейство | Прямые | Курсив |
|---|---|---|
| SB Sans Interface | `300`, `400`, `600`, `700` | `300`, `400`, `600` |
| SB Sans Interface Caps | `400` | — |
| SB Sans Text | `250`, `300`, `400`, `600`, `700` | `300`, `400`, `600`, `700` |
| SB Sans Display | `250`, `300`, `400`, `500`, `600`, `700` | — |
| SB Sans Text Mono | `400`, `700` | — |
| Inter | `100`–`900` (variable) | `100`–`900` (variable) |
| Roboto Mono | `100`–`700` (variable) | `100`–`700` (variable) |

Промежуточные веса из токенов (`350`, `450`, `550`, `650`) браузер берёт из ближайшего зарегистрированного начертания.
