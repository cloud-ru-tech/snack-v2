# RichText

`@ds/site-rich-text` — Блок форматированного текста для сайта — HTML-строка или ReactNode со стилями абзацев, ссылок, списков и изображений.

Контейнер для текста из CMS сайта. Принимает HTML-строку или ReactNode и задаёт базовые стили вложенной разметке: обнуляет отступы абзацев и списков, подчёркивает ссылки и меняет их цвет при наведении, ограничивает ширину изображений. Шрифт и цвет текста наследуются от родителя.

HTML-строка перед вставкой очищается от XSS через DOMPurify: удаляются скрипты, обработчики событий, ссылки `javascript:`, стили и элементы форм. Подробности — в разделе [Источник содержимого](#источник-содержимого-content).

## Когда использовать

- Заголовок, подзаголовок или описание секции сайта, где разметка приходит из CMS (ссылки, переносы, списки).
- Статья или текстовый блок с вложенными изображениями.

Когда **не** нужен:

- Обычный текст без разметки:
  - используйте **`@ds/typography`**.
- Отдельная ссылка:
  - используйте **`@ds/link`**.

## Анатомия

Стили применяются к вложенным элементам:

- `p` — без внешних отступов.
- `a` — подчёркивание, цвет текста родителя, при наведении — `primary/text`.
- `ul`, `ol` — без внешних отступов, отступ слева `primitive/dimension/20`.
- `img` — ширина не больше контейнера, отступ снизу `primitive/dimension/24` (кроме последнего).

### Источник содержимого (`content`)

- `string` — HTML-разметка. Перед вставкой очищается через DOMPurify (`isomorphic-dompurify`), одинаково на сервере и в браузере. Удаляются:
  - скрипты, обработчики `on*`, ссылки `javascript:`;
  - теги и атрибуты `style`;
  - элементы форм;
  - SVG и MathML.

  Ссылкам с `target` добавляется `rel="noopener noreferrer"`: открытая страница не получает доступ к `window.opener`.
- `ReactNode` — рендерится как дочерние элементы, без очистки: React сам экранирует текст.

### Tag (default `div`)

Тег корневого элемента:

- `div` — блок с абзацами, списками и изображениями.
- `span` — строчный элемент внутри абзаца или подписи.
- `h1`–`h4` — заголовок: разметка вставляется прямо в заголовок, без вложенной обёртки. Так рендерит заголовок `@ds/site-section-title`.

Тег задаёт только семантику: стили заголовков браузера по умолчанию (жирное начертание, крупный кегль, отступы) сброшены. Типографику задаёт родитель или `className`.

В `span` и заголовки передавайте только строчную разметку (`a`, `strong`, `em`, `br`): абзацы и списки внутри них недопустимы по HTML.

## Установка

```bash
pnpm add @ds/site-rich-text
```

```ts
import { RichText } from '@ds/site-rich-text'
```

## Примеры использования

### HTML-строка

Разметка из CMS передаётся строкой

```tsx
import { RichText } from '@ds/site-rich-text';

const HTML = '<p>Облачная платформа для <a href="https://cloud.ru">разработки и запуска</a> приложений.</p>';

export function HtmlString() {
  return <RichText content={HTML} />;
}
```

### ReactNode

Та же разметка в JSX — без вставки HTML

```tsx
import { RichText } from '@ds/site-rich-text';

export function ReactNodeContent() {
  return (
    <RichText
      content={
        <p>
          Облачная платформа для <a href='https://cloud.ru'>разработки и запуска</a> приложений.
        </p>
      }
    />
  );
}
```

### Списки

Маркированный и нумерованный списки

```tsx
import { RichText } from '@ds/site-rich-text';

const HTML = [
  '<ul><li>Виртуальные машины</li><li>Managed Kubernetes</li></ul>',
  '<ol><li>Создайте проект</li><li>Подключите репозиторий</li></ol>',
].join('');

export function Lists() {
  return <RichText content={HTML} />;
}
```

## Props

**RichTextProps**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | — | CSS-класс корневого элемента. |
| `content` | `ReactNode` | `` | Содержимое блока. <br/> - `string` — HTML-разметка. Перед вставкой очищается DOMPurify: удаляются скрипты, обработчики `on*`, <br/> ссылки `javascript:`, стили, элементы форм, SVG и MathML. <br/> - `ReactNode` — рендерится как дочерние элементы. |
| `data-test-id` | `string` | — |  |
| `tag` | `"div"` \| `"h1"` \| `"h2"` \| `"h3"` \| `"h4"` \| `"span"` | `div` | Тег корневого элемента. Задаёт только семантику: стили заголовков браузера по умолчанию сброшены, <br/> типографику задаёт родитель или `className`. <br/> В строчный элемент и заголовок передавайте только строчную разметку (`a`, `strong`, `em`, `br`): <br/> абзацы и списки внутри них недопустимы по HTML. |
