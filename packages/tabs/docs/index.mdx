## Overview

**Tabs** — составной компонент. Используется как контейнер `Tabs` с вложенными `Tabs.TabBar` (панель вкладок), `Tabs.Tab` (кнопки вкладок) и `Tabs.TabContent` (контент по значению выбранной вкладки).

Компонент обеспечивает:

- **Горизонтальные и вертикальные табы** — ориентация задаётся на `TabBar` (`orientation`: horizontal | vertical). При вертикальной ориентации панель табов слева, контент справа.
- **Размер** — L (крупный заголовок) и M (мелкий, на уровне контента). Задаётся на `TabBar` через проп `size`.
- **Маркер выбранной вкладки** — полоска/линия по макету; позиция `markerPosition`: before | after (сверху/слева или снизу/справа от панели).
- **Счётчик на вкладке** — опциональный проп `counter` у `Tabs.Tab` с полем `label` (число) и опционально `appearance`, `color`.
- **Скролл при переполнении** — при большом количестве вкладок появляются кнопки прокрутки (слева/справа или сверху/снизу), позиционируются абсолютно по краям области скролла.
- **Управление** — контролируемый режим (`value` + `onChange`) или неконтролируемый (`defaultValue`).

## Usage

### Basic example (horizontal)

```tsx
import { Tabs } from '@design-system/tabs';

export function Example() {
  return (
    <Tabs defaultValue="tab1">
      <Tabs.TabBar>
        <Tabs.Tab label="Вкладка 1" value="tab1" />
        <Tabs.Tab label="Вкладка 2" value="tab2" />
        <Tabs.Tab label="Вкладка 3" value="tab3" />
      </Tabs.TabBar>
      <Tabs.TabContent value="tab1">Контент 1</Tabs.TabContent>
      <Tabs.TabContent value="tab2">Контент 2</Tabs.TabContent>
      <Tabs.TabContent value="tab3">Контент 3</Tabs.TabContent>
    </Tabs>
  );
}
```

### Controlled mode

```tsx
import { Tabs } from '@design-system/tabs';

  const [value, setValue] = useState('tab1');

      <Tabs.TabContent value="tab2">Контент 2</Tabs.TabContent>

```

## Props

### TabsProps

| name | type | default | description |
|------|------|---------|-------------|
| value | `string` | - | Текущая выбранная вкладка (контролируемый режим) |
| defaultValue | `string` | - | Выбранная вкладка по умолчанию (неконтролируемый режим) |
| onChange | `(id: string) => void` | - | Колбек при смене вкладки |
| children | `ReactNode` | - | Дочерние элементы: TabBar, TabContent |

### TabBarProps

| name | type | default | description |
|------|------|---------|-------------|
| children | `ReactElement<TabProps>[]` | - | Элементы Tabs.Tab |
| size | `'l' \| 'm'` | `'l'` | Размер панели (L — крупный, M — мелкий) |
| orientation | `'horizontal' \| 'vertical'` | `'horizontal'` | Ориентация панели табов |
| markerPosition | `'before' \| 'after'` | `'after'` | Позиция маркера выбранной вкладки |
| after | `ReactNode` | - | Дополнительный контент справа от табов (horizontal) или после панели (vertical) |
| disableDivider | `boolean` | `false` | Скрыть разделитель под/рядом с панелью табов |
| className | `string` | - | CSS-класс |

### TabProps

| name | type | default | description |
|------|------|---------|-------------|
| value* | `string` | - | Идентификатор вкладки |
| label* | `string` | - | Текст вкладки |
| disabled | `boolean` | `false` | Неактивная вкладка (фокус сохраняется для a11y) |
| counter | `{ label: number; appearance?: ...; color?: ... }` | - | Счётчик на вкладке |
| onClick | `(event) => void` | - | Колбек клика по вкладке |
| className | `string` | - | CSS-класс |

### TabContentProps

| name | type | default | description |
|------|------|---------|-------------|
| value* | `string` | - | Идентификатор вкладки (контент показывается при совпадении с выбранной) |
| children | `ReactNode` | - | Контент панели |
| className | `string` | - | CSS-класс |

## Accessibility

- **Роли** — панель табов имеет `role="tablist"`, каждая вкладка `role="tab"`, контент — `role="tabpanel"`. Связь через `aria-controls`, `aria-labelledby`, `id` панели.
- **Клавиатура** — стрелки влево/вверх и вправо/вниз переключают фокус между вкладками, Enter/Space выбирают вкладку. Отключённые вкладки остаются фокусируемыми с `aria-disabled="true"`, клик и активация по клавишам блокируются.
- **Скролл** — кнопки прокрутки имеют `aria-label` (например, "Scroll left", "Scroll top") и не участвуют в таб-навигации (`tabIndex={-1}`).

## Best practices

1. **Структура** — всегда используйте состав: `Tabs` → `Tabs.TabBar` с `Tabs.Tab` внутри и один или несколько `Tabs.TabContent` с тем же `value`, что и у вкладок.
2. **Ориентация** — горизонтальные табы для основного переключения разделов; вертикальные — для боковой навигации или когда заголовков много.
3. **Счётчики** — используйте `counter` для числа элементов (уведомления, заявки). Не перегружайте панель большим количеством вкладок; при переполнении появятся кнопки скролла.
4. **Контроль** — для синхронизации с URL или состоянием страницы используйте контролируемый режим (`value` + `onChange`).
