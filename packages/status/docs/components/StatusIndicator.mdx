## Accessibility

- Компонент отображает визуальную точку; при использовании внутри контекста (например, в Status или рядом с текстом) контекст обеспечивает доступность для скринридеров

## Best practices

1. **В паре с текстом** — Для самостоятельного использования предпочтительнее **Status** с подписью; StatusIndicator — для встраивания в свои блоки
2. **Подбирайте appearance** — По умолчанию primary; используйте цветные варианты для семантики статуса
3. **Размер по контексту** — Меньшие размеры (4xs, 3xs) для плотных списков и таблиц, s — для карточек и основных экранов
