# Status

Пакет `@ds/status` содержит два компонента для отображения состояния сущности:

- [**Status**](/components/status/status) — подпись с цветным маркером. Маркер может быть точкой, спиннером (`loading`) или круговым прогресс-баром (`progress`).
- [**StatusIndicator**](/components/status/status-indicator) — только маркер-точка без текста: для мест, где подпись избыточна (иконка в таблице, badge на иконке).

## Установка

```bash
pnpm add @ds/status
```

```ts
import { Status, StatusIndicator } from '@ds/status'
```
