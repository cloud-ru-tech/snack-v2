# Status

Пакет `@ds/status` содержит два компонента для отображения состояния сущности:

- [**Status**](/components/status/status) — подпись с цветным маркером. Маркер может быть точкой, спиннером (`loading`) или круговым прогресс-баром (`progress`).
- [**StatusIndicator**](/components/status/status-indicator) — только маркер-точка без текста: для мест, где подпись избыточна (иконка в таблице, badge на иконке).

## Установка

```bash
pnpm add @ds/status
```

```ts
import { Status, StatusIndicator } from '@ds/status'
import '@ds/status/style.css'
```

## Когда какой использовать

| Задача | Компонент |
|--------|-----------|
| Статус в списке / таблице с текстом | `Status` |
| Запущенный процесс со спиннером | `Status` + `loading` |
| Прогресс обработки (0–100%) | `Status` + `progress` |
| Иконка-индикатор без подписи | `StatusIndicator` |
| Badge на аватаре / иконке | `StatusIndicator` |

## Общие принципы

- **Цветовая семантика.** `green` — успех/активно, `red` — ошибка/деструктивно, `yellow/orange` — предупреждение, `neutral` — в ожидании или отключено, `blue/violet` — информационные.
- **Цвет не единственный носитель смысла.** Текст в `label` всегда дублирует смысл цвета («Active», «Error», «Pending»).
- **Размер согласован с контекстом.** `xs` — плотные списки, `s` — карточки.
