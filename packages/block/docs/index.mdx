# Block

`Block` — универсальный контейнер-слот с акриловой подложкой (backdrop-blur). Подходит для плавающих панелей, карточек над изображением, оверлеев и всплывающих блоков, где нужно сохранить читаемость контента на любом фоне.

## Когда использовать

- Плавающие карточки или панели поверх фоновых изображений.
- Модальные и всплывающие поверхности, где важна глубина.
- Любой контент, который нужно визуально отделить от сложного фона без использования сплошного цвета.

Когда **не** нужен `Block`: для обычных блоков на плоском фоне используйте свёрстанную карточку без акрилового эффекта — Block заметно дороже по отрисовке.

## Для дизайнеров

### Variant — вариант подложки

| Variant | Когда использовать |
|---------|--------------------|
| `simple` | Базовый акриловый фон — по умолчанию |
| `outline` | С обводкой — на фонах, где контуры теряются |
| `shadow` | С тенью — для плавающего ощущения (меню, тултипы) |
| `transparent` | Полупрозрачное матовое стекло — максимально лёгкая подложка |

### Size — размер

| Size | Типичный сценарий |
|------|--------------------|
| `s` | Компактные панели, inline-кнопки |
| `m` | Средние карточки, попап |
| `l` | Крупные поверхности, модалки |

### Do / Don't

- ✅ Сплошной фон или изображение за Block — иначе акриловый эффект не читается.
- ❌ Block на белом фоне — эффект не виден, используйте обычную карточку.
- ✅ Один Block на группу связанного контента.
- ❌ Вложенные Block — двойной blur ломает читаемость.

## Доступность

- Block — визуальная подложка, семантики роли не несёт. Рендерится как `<div>`.
- Для интерактивных поверхностей (модалки, меню) оборачивайте Block в соответствующий семантический элемент (`<dialog>`, `role='menu'`).
- Проверяйте контраст текста на выбранной подложке: `transparent` на пёстром фоне может падать ниже AA.
