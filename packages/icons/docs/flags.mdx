# Flags

Флаги стран. В отличие от интерфейсных наборов (`system`/`product`/`web`), флаги сохраняют исходные цвета SVG — `currentColor` их бы визуально сломал. Sprite-вариант не генерируется: только standalone-компоненты.

## Когда использовать

- Для отображения страны в списках, селектах, профилях пользователей.
- Не используйте флаги как единственный индикатор языка интерфейса — язык и страна не всегда совпадают.

## Установка

```ts
import { RussiaSVG } from '@ds/icons/flags'
```
