# System

Базовый набор интерфейсных иконок дизайн-системы: действия (копировать, удалить, поиск), навигация (стрелки, шевроны), состояния (успех, предупреждение, ошибка) и типографские иконки (заголовки, списки). Самый широко используемый набор пакета.

## Когда использовать

- Для универсальных действий и состояний интерфейса, не привязанных к конкретному продукту или домену.
- Как источник иконок по умолчанию для новых компонентов — прежде чем искать иконку в `product` или `web`, проверьте `system`.

## Установка

```ts
import { SearchSVG, ArrowDownSVG, CheckSVG } from '@ds/icons/interface/system'
```

Каждый компонент этой группы сам рендерит `<use href="#...">` на символ спрайта (с инлайн-fallback, если спрайт не смонтирован) — отдельного `*SpriteSVG`-экспорта нет, см. страницу [Sprite](/components/icons/sprite).
