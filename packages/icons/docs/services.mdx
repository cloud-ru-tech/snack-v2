# Services

Иконки конкретных облачных сервисов и продуктов: вычисления, сети, хранилища, Kubernetes-объекты, ML Space, VMware, партнёрские интеграции. Наследуют цвет через `currentColor`.

## Когда использовать

- В каталоге сервисов, карточках продуктов, навигации по конкретному облачному сервису.
- Не путайте с `product` — там общие продуктовые UI-действия, здесь — обозначения самих сервисов.

## Установка

```ts
import { AirflowSVG } from '@ds/icons/services'
```

Каждый компонент сам рендерит `<use href="#...">` на символ спрайта (с инлайн-fallback, если спрайт не смонтирован) — см. страницу [Sprite](/components/icons/sprite). Спрайт группы — `SpriteServicesSVG` из `@ds/icons/sprite`.
