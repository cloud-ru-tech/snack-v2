# Logos

Логотипы облачных сервисов и сторонних брендов. Каждый логотип — единый компонент, который сам читает текущую тему через `useThemeAppearance()` из `@ds/theme` и переключается между Light- и Dark-исполнением; отдельно управлять вариантом не нужно. Цвет сохраняется как в исходном SVG, sprite-вариант не генерируется.

## Когда использовать

- Для отображения бренда стороннего сервиса или продукта Cloud.ru (карточки интеграций, страницы партнёров, маркетплейс).
- Не используйте для собственных интерфейсных иконок — для этого `system`/`product`/`web`.

## Установка

```ts
import { CloudLogo } from '@ds/icons/logos'
```
