# Web

Тематический набор иконок для веб-продуктов: облачная инфраструктура (Data Center, Databases/Repos), браузер, файлы, HR-портал, AI, страницы решений, состояния. Более узкоспециализированный набор, чем `system`/`product`.

## Когда использовать

- Для иллюстрации облачной инфраструктуры, дата-центров, баз данных и связанных технических сущностей.
- Для HR-портала, AI-сценариев и тематических посадочных страниц решений.

## Установка

```ts
import { CloudArrowSVG, CloudChartSVG } from '@ds/icons/interface/web'
```

Каждый компонент этой группы сам рендерит `<use href="#...">` на символ спрайта (с инлайн-fallback, если спрайт не смонтирован) — отдельного `*SpriteSVG`-экспорта нет, см. страницу [Sprite](/components/icons/sprite).
