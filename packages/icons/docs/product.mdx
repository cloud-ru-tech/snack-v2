# Product

Набор иконок для продуктовых сценариев: файлы, таблицы, реакции, соцсети, MKP/LKP-специфика. Используется там, где `system` не хватает — для доменных сущностей и продуктовых действий.

## Когда использовать

- Для продуктовых сущностей и действий, специфичных для конкретных разделов приложения (файлы, таблицы, соцсети, маркетплейс).
- Если нужной иконки нет в `system` — сначала проверьте здесь, прежде чем заводить новую иконку в Figma.

## Установка

```ts
import { CloudSVG, BoxSVG, DotSmallSVG } from '@ds/icons/interface/product'
```

Каждый компонент этой группы сам рендерит `<use href="#...">` на символ спрайта (с инлайн-fallback, если спрайт не смонтирован) — отдельного `*SpriteSVG`-экспорта нет, см. страницу [Sprite](/components/icons/sprite).
