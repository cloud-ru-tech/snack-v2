# Extensions

Иконки типов файлов по расширению. Наследуют цвет через `currentColor`.

## Когда использовать

- В списках загруженных файлов, дропзонах, файловых менеджерах — обозначить тип файла по расширению.
- Смотрите также [`@ds/uikit-product-upload-files`](/components/uikit-product-upload-files), где эти иконки уже подключены как дефолтный резолвер.

## Установка

```ts
import { AacExtensionSVG } from '@ds/icons/extensions'
```

Каждый компонент сам рендерит `<use href="#...">` на символ спрайта (с инлайн-fallback, если спрайт не смонтирован) — см. страницу [Sprite](/components/icons/sprite). Спрайт группы — `SpriteExtensionsSVG` из `@ds/icons/sprite`.
