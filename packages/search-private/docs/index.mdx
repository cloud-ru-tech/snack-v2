# Search Private

Компонент поля поиска с иконкой лупы, кнопкой очистки при непустом значении и опциональным состоянием загрузки. Поддерживает controlled и uncontrolled режимы, подтверждение поиска по Enter.

## Overview

Search Private — поле ввода для поиска в стиле design system. Компонент автоматически обеспечивает:

- **Три размера** — `s`, `m`, `l` для согласованного отображения в разных контекстах
- **Иконка и состояние загрузки** — слева отображается иконка поиска или индикатор загрузки (Sun) при `loading={true}`
- **Кнопка очистки** — справа появляется кнопка очистки при непустом значении; после очистки фокус возвращается в поле
- **Подтверждение по Enter** — колбек `onSubmit(value)` вызывается при нажатии Enter с текущей строкой поиска
- **Локализация** — плейсхолдер по умолчанию берётся из локали (`Search` / `Поиск`)

## Usage

### Basic example

```tsx
import { SearchPrivate } from '@design-system/search-private';

export function Example() {
  return <SearchPrivate />;
}
```

### Controlled с onSubmit

```tsx
import { SearchPrivate } from '@design-system/search-private';

export function Example() {
  const handleSearch = (value: string) => {
    console.log('Поиск:', value);
  };

  return <SearchPrivate onSubmit={handleSearch} />;
}
```

### С состоянием загрузки и кастомным placeholder

```tsx
import { SearchPrivate } from '@design-system/search-private';

export function Example() {
  return (
    <SearchPrivate
      loading
      placeholder="Ищем..."
      size="m"
    />
  );
}
```

## Accessibility

- Поле реализовано на базе `InputPrivate` с семантичным `input` и `inputMode="search"`
- Кнопка очистки доступна с клавиатуры; навигация между полем и кнопкой через Tab
- После очистки фокус возвращается в поле ввода
- Компонент поддерживает пропсы `WithSupportProps` (в т.ч. data-test-id) для тестов и кастомизации

## Best practices

1. **Используйте onSubmit для отправки поиска** — обрабатывайте подтверждение по Enter в `onSubmit`, не дублируйте логику в `onChange`.
2. **Показывайте loading при запросе** — передавайте `loading={true}` во время загрузки результатов, чтобы пользователь видел индикатор.
3. **Контролируйте значение при фильтрации** — для живого поиска используйте `value` и `onChange`; для поиска «по кнопке/Enter» достаточно `onSubmit`.
