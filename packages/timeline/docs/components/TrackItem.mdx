# TrackItem

**TrackItem** — составная часть **Timeline**: flex-строка с колонкой **Track** и областью **`content`** (и опционально **`opposite`**). Не входит в публичный `export` корня `@design-system/timeline`; для кастомных лент можно импортировать модуль из исходников монорепозитория.

## Usage

Импорт из исходников пакета (путь в монорепозитории):

```tsx
import { TrackItem } from '@packages/timeline/src/components/TrackItem';

export function Example() {
  return (
    <TrackItem
      role='start'
      lineStyle='solid'
      dotVariant='default'
      dotAppearance='primary'
      showLines
      content={<span>Контент</span>}
    />
  );
}
```

Константы на объекте компонента: **`TrackItem.roles`**, **`TrackItem.contentPositions`**, **`TrackItem.dotVariants`**, **`TrackItem.dotAppearances`**, **`TrackItem.lineStyles`**.

## Props

### TrackItemProps

| name            | type                               | default value | description                                                |
| --------------- | ---------------------------------- | ------------- | ---------------------------------------------------------- |
| content\*       | `ReactNode`                        | -             | Основной контент                                           |
| role\*          | `"start"` \| `"center"` \| `"end"` | -             | Позиция в цепочке (линии сверху/снизу)                     |
| contentPosition | `"right"` \| `"left"`              | right         | Сторона контента относительно трека                        |
| opposite        | `ReactNode`                        | -             | Вторая колонка; пустой блок рендерится при `alternateMode` |
| lineStyle       | `"solid"` \| `"dashed"`            | -             | Стиль нижнего сегмента линии                               |
| dotVariant      | `"default"` \| `"subEvent"`        | default       | Вид маркера                                                |
| dotAppearance   | см. тему                           | neutral       | Цвет маркера                                               |
| showLines       | `boolean`                          | true          | Показывать вертикальные сегменты                           |
| alternateMode   | `boolean`                          | -             | Резервировать колонку opposite для сетки                   |

## Accessibility

- Те же **`data-test-id`**, что у встроенного использования в **Timeline** (`timeline-track-item`, `timeline-track-item-opposite`).

## Best practices

1. Предпочитайте **`Timeline`**, если не нужна кастомная разметка между пунктами.
2. Согласуйте **`role`** с позицией в списке (как делает **Timeline** автоматически).
