# Timeline

Пакет `@ds/timeline` предоставляет компоненты для построения вертикальной ленты событий: хронологии заявки, этапов процесса, истории изменений.

- [**Timeline**](/components/timeline/timeline) — контейнер ленты, задаёт общий layout и направление.
- [**TrackItem**](/components/timeline/track-item) — отдельное событие с маркером, соединительной линией и контентом.
