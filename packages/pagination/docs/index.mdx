# Pagination

Пакет `@ds/pagination` предоставляет два компонента для постраничной навигации по длинным спискам:

- [**Pagination**](/components/pagination/pagination) — классическая постраничная навигация с нумерацией и свёрткой середины диапазона.
- [**PaginationSlider**](/components/pagination/pagination-slider) — компактный «слайдер-индикатор» страницы для коротких наборов, карточек и onboarding.

## Установка

```bash
pnpm add @ds/pagination
```

```ts
import { Pagination, PaginationSlider } from '@ds/pagination'
```
