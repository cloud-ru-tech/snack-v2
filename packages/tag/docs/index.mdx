# Tag

Пакет `@ds/tag` содержит компоненты для отображения коротких меток, категорий и статусов:

- [**Tag**](/components/tag/tag) — одиночная метка. Рендерится как `<span>` по умолчанию, как `<a>` при передаче `href`, и опционально отображает кнопку удаления через `onDelete`.
- [**TagRow**](/components/tag/tag-row) — контейнер группы меток. Поддерживает ограничение по количеству видимых строк с кнопкой «+N ещё».

## Установка

```bash
pnpm add @ds/tag
```

```ts
import { Tag, TagRow } from '@ds/tag'
```
