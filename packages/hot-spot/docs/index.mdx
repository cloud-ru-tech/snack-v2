# Hot Spot

Компонент для привлечения внимания к элементу — цветная точка с опциональной анимацией пульсации. Может отображаться отдельно или поверх контента (children) с настраиваемым позиционированием.

**Version:** `{frontmatter.version}`

Поддерживает:
- **Appearance** — neutral, primary, red, orange, yellow, green, blue, violet, pink — цвет точки
- **Pulse** — анимация пульсации (опционально)
- **Placement** — 9 вариантов позиций относительно children (left, right, center, top, bottom)
- **Offset** — смещение dot по осям X и Y
- Figma: [HotSpot](https://www.figma.com/design/aNPU3MHwRJiEwbk5F82zux/Snack-Ui-Kit-variables?node-id=8968-2435&m=dev)

## Overview

Hot Spot рендерит точку (8×8 px) с опциональной анимацией пульсации. Может использоваться без children (только dot) или с обёрткой — dot поверх контента в абсолютной позиции.

- **Без children** — возвращает только dot в контейнере
- **С children** — обёртка с children и dot, позиционируемым через `placement` (right-top по умолчанию)
- **enabled** — при `false` отображаются только children (без dot)
- **dotRender** — кастомная функция для обёртки dot (например, обёртка в Tooltip)

Стили из `@sbercloud/figma-variables` (anatomy dot/pulse, theme colors).

## Usage

### Basic example

```tsx
import { HotSpot } from '@design-system/hot-spot';

export function Example() {
  return <HotSpot />;
}
```

По умолчанию: `appearance="primary"`, `pulse={true}`, `placement="right-top"`.

### With appearance and pulse

```tsx
import { HotSpot, APPEARANCE } from '@design-system/hot-spot';

export function Example() {
  return (
    <>
      <HotSpot appearance={APPEARANCE.Red} />
      <HotSpot appearance={APPEARANCE.Green} pulse={false} />
    </>
  );
}
```

### With children and placement

```tsx
import { HotSpot, PLACEMENT } from '@design-system/hot-spot';

export function Example() {
  return (
    <HotSpot placement={PLACEMENT.RightTop}>
      <button type="button">Кнопка с индикатором</button>
    </HotSpot>
  );
}
```

### With offset

```tsx
import { HotSpot } from '@design-system/hot-spot';

export function Example() {
  return (
    <HotSpot offsetX={8} offsetY={-4}>
      <span>Элемент</span>
    </HotSpot>
  );
}
```

### Conditional display (enabled)

```tsx
import { HotSpot } from '@design-system/hot-spot';

export function Example({ hasUpdates }: { hasUpdates: boolean }) {
  return (
    <HotSpot enabled={hasUpdates}>
      <button type="button">Меню</button>
    </HotSpot>
  );
}
```

## Accessibility

- Точка — декоративный элемент; при необходимости добавляйте `aria-label` или `aria-describedby` к родительскому интерактивному элементу.
- При использовании с `dotRender` (например, обёртка в Tooltip) обеспечивайте доступность подсказки.
- Компонент принимает стандартные HTML-атрибуты через WithSupportProps.

## Best practices

1. **Appearance** — подбирайте цвет под контекст (primary для основного, red для критичных уведомлений).
2. **Pulse** — анимация привлекает внимание; отключайте `pulse={false}` при избыточном количестве индикаторов.
3. **Placement** — используйте `right-top` для кнопок и иконок; `center` для центрирования.
4. **enabled** — скрывайте dot при отсутствии уведомлений (`enabled={hasUpdates}`).
5. **dotRender** — для кастомной обёртки (Tooltip, Popover) передавайте функцию, возвращающую обёрнутый dot.
