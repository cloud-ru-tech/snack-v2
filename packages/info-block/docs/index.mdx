# InfoBlock

Типовой блок информации: заголовок, описание, опциональные иконка и футер с действиями. Используется в пустых состояниях, онбординге, подсказках и хедерах разделов.

## Демо

<InfoBlockDemo client:load />

## Когда использовать

- Пустое состояние списка/таблицы («Нет данных», «Ничего не найдено»).
- Подсказка внутри формы или карточки.
- Заголовок раздела с подзаголовком и кнопками действия.
- Информационная вставка над списком — например, объяснение статуса.

Когда **не** нужен: если нужен только заголовок без описания — возьмите `Typography`. Если нужна полноценная карточка с рамкой — возьмите компонент-карточку.

## Для дизайнеров

### Size

| Size | Применение |
|------|------------|
| `s` | Встроенная подсказка, строка в списке |
| `m` | Значение по умолчанию — карточки, формы |
| `l` | Пустое состояние на весь экран, онбординг |

### Align

| Align | Эффект |
|-------|--------|
| `vertical` | Иконка сверху, текст снизу — вертикальная колонка |
| `horizontal` | Иконка слева, текст справа — строка |

### Do / Don't

- ✅ Один короткий заголовок + 1–2 строки описания.
- ❌ Простыня текста в `description` — уносите в отдельную страницу.
- ✅ `footer` — максимум два действия (primary + secondary).
- ❌ Три и больше кнопок в футере — пересматривайте иерархию.
- ✅ Иконка поддерживает заголовок смыслово (предупреждение, успех, пустое состояние).
- ❌ Декоративная иконка без связи с содержанием.

## Доступность

- Заголовок и описание — простой текст в отдельных `<div>`; выравнивание визуальное.
- Иконка, если декоративная, не помечена `role`/`aria-label` — её скринридер не объявит.
- Фокус внутри `footer` ведёт себя как обычно для вложенных кнопок.
- Цветовые акценты иконки не являются единственным носителем смысла — дублируйте состоянием в тексте.
