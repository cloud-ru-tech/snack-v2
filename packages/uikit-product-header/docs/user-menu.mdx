# UserMenu

`UserMenu` — dropdown с профилем пользователя, переключателем темы, дополнительными пунктами и кнопкой выхода.

## Когда использовать

- Блок аккаунта в правой части шапки консоли.
- Переключение light / dark / system темы из интерфейса.
