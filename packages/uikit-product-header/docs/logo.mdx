# Logo

`Logo` — ссылка на главную с иконкой Cloud или кастомным изображением. Поддерживает badge режима окружения (`develop`, `stage`, `hybrid`).

## Когда использовать

- Слот `logo` в `HeaderLayout`.
- Отображение режима стенда рядом с логотипом.
