# PathBreadcrumbs

`PathBreadcrumbs` — продуктовая обёртка `@ds/breadcrumbs` для слота `breadcrumbs` в `HeaderLayout`.

## Когда использовать

- Отображение пути навигации в центральной зоне шапки.
- Длинные цепочки разделов с автоматическим truncate.
