# Changelog

All notable changes to `@design-system/button` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-01-15

### Added

- Initial release of Button component
- Support for three variants: `primary`, `secondary`, `ghost`
- Three size options: `sm`, `md`, `lg`
- `isFullWidth` prop for full-width buttons
- Full TypeScript support with proper type definitions
- Accessibility features: proper ARIA attributes, keyboard navigation
- IconButton component for icon-only buttons

### Documentation

- Complete component documentation with examples
- Storybook stories for all variants and sizes
- Usage examples and API reference

## [Unreleased]

### Planned

- Loading state support
- Disabled state styling improvements
- Icon positioning options (left/right)
- Button group component
