# ButtonGroup

Группа действий: primaryAction (filled), secondaryAction (outline), tertiaryAction (simple). Поддерживает size, vertical, centered, break, filled. Используется в InfoBlock и других компонентах.

- **primaryAction** — основное действие (filled)
- **secondaryAction** — вторичное действие (outline), опционально
- **tertiaryAction** — третичное действие (simple/text-only), опционально
- **size** — s, m, l
- **vertical** — вертикальное расположение
- **centered** — центрирование по горизонтали
- **break** — перенос на новую строку при нехватке места
- **filled** — заливка контейнера
- **tooltip** — для каждой кнопки можно передать tooltip

## Usage

### Basic

```tsx
import { ButtonGroup } from '@design-system/button';

export function Example() {
  return (
    <ButtonGroup
      primaryAction={{ label: 'Подтвердить' }}
      secondaryAction={{ label: 'Отмена' }}
    />
  );
}
```

### Primary only

```tsx
import { ButtonGroup } from '@design-system/button';

<ButtonGroup primaryAction={{ label: 'Продолжить' }} />
```

### With callbacks

```tsx
import { ButtonGroup } from '@design-system/button';

<ButtonGroup
  primaryAction={{ label: 'Сохранить', onClick: () => handleSave() }}
  secondaryAction={{ label: 'Отмена', onClick: () => handleCancel() }}
/>
```

### In InfoBlock footer

```tsx
import { InfoBlock } from '@design-system/info-block';
import { ButtonGroup } from '@design-system/button';

<InfoBlock
  title="Заголовок"
  description="Описание"
  footer={
    <ButtonGroup
      primaryAction={{ label: 'Подтвердить' }}
      secondaryAction={{ label: 'Отмена' }}
    />
  }
/>
```

## Accessibility

- Все действия рендерятся как нативные `<button>` с корректной семантикой и фокусом по Tab.
- Порядок: tertiary → secondary → primary — соответствует визуальному порядку слева направо (или сверху вниз при vertical).

## Best practices

1. **Primary action** — используйте primaryAction для основного действия (подтвердить, сохранить), secondaryAction для отмены, tertiaryAction для дополнительных действий.
2. **Одна кнопка** — если действие одно, передавайте только `primaryAction`.
3. **В InfoBlock** — ButtonGroup типично используется в `footer` InfoBlock для действий по блоку.
