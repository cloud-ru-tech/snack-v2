# defineColumns

`defineColumns` преобразует декларативный массив `SimpleColumnDef<T>[]` в `ColumnDefinition<T>[]` для [`Table`](/components/table/table) и всех preset-ов (`SimpleTable`, `AdminTable`, …).

Всегда задаёт `id = key` — это нужно для resize и `savedState`.

## Когда использовать

- Обычные колонки с `header`, `sortable`, `width`, `format`.
- Не хотите вручную собирать `ColumnDefinition` для каждого поля.

Когда **не** нужен:

- Сложная кастомная ячейка — передайте полный `column` через escape hatch или используйте `getStatusColumnDef` / `getRowActionsColumnDef` напрямую.
