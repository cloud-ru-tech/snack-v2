# Materials

Пакет экспортирует SCSS-миксины без JS runtime — используется другими пакетами как `@use '@ds/materials' as m`.

## Состав

- `material/_acrylic.scss` — акриловый эффект (blur + полупрозрачный фон)
- `stateLayer/index.scss` — state-layer для hover/pressed состояний
- `utils/_mixins.scss` — вспомогательные миксины (`has-state-layer-as-child`, `has-content-with-text-opacity`)

## Использование

```scss
// packages/button/src/styles.module.scss
@use '@ds/materials' as m;

.root {
  @include m.has-state-layer-as-child(#{stateLayer});
}
```

## Установка

```bash
pnpm add @ds/materials
```
