# Popover

Публичный компонент поповера со стилями по макету Figma. Строится на PopoverPrivate (Floating UI). Предназначен для выпадающих блоков с произвольным контентом: меню, формы, подсказки с действиями и т.п. В отличие от Tooltip, контент передаётся через проп `content`, триггер — через `children`; по умолчанию открывается по клику.

## Overview

**Popover** — обёртка над PopoverPrivate с готовыми стилями контейнера и стрелки по дизайн-системе (токены из `@sbercloud/figma-variables`). Контейнер: светлый фон, скругления, тень level2, отступ от триггера и размеры стрелки заданы анатомией поповера.

Компонент обеспечивает:

- **Контент и триггер** — слот контента через проп `content`, триггер — через `children` (кнопка, ссылка, иконка и т.д.).
- **Триггеры открытия** — по умолчанию `click`; доступны `hover`, `focus`, `focusVisible` и комбинации. Для hover настраиваются задержки `hoverDelayOpen` и `hoverDelayClose`.
- **Позиционирование** — 12 вариантов `placement` (top, bottom, left, right и -start/-end). При нехватке места срабатывает flip по `fallbackPlacements`.
- **Стрелка** — по умолчанию включена (`hasArrow={true}`), стили из design tokens.
- **Размеры** — стратегии ширины (`widthStrategy`: auto, gte, eq) и высоты (`heightStrategy`: auto, lte, eq). Закрытие по клику вне (`outsideClick`), по Escape (`closeOnEscapeKey`), при навигации по истории (`closeOnPopstate`).

От **Tooltip** Popover отличается: другим визуальным стилем (светлый контейнер с тенью), API (`content` вместо `tip`), дефолтным триггером (click вместо hover) и отсутствием ограничения ширины и инвертированной палитры.

## Usage

### Basic example

```tsx
import { Popover } from '@design-system/popover';

export function Example() {
  return (
    <Popover content={<span>Текст или разметка</span>}>
      <button type="button">Открыть</button>
    </Popover>
  );
}
```

### С указанием placement и trigger

```tsx
import { Popover, PLACEMENT, TRIGGER } from '@design-system/popover';

export function Example() {
  return (
    <Popover
      content={<div>Произвольный контент</div>}
      placement={PLACEMENT.Right}
      trigger={TRIGGER.Click}
      hasArrow
    >
      <button type="button">Меню</button>
    </Popover>
  );
}
```

### По hover с задержкой

```tsx
import { Popover, TRIGGER } from '@design-system/popover';

export function Example() {
  return (
    <Popover
      content={<div>Дополнительная информация</div>}
      trigger={TRIGGER.Hover}
      hoverDelayOpen={200}
      hoverDelayClose={100}
    >
      <button type="button">Наведи</button>
    </Popover>
  );
}
```

### Контролируемый режим

```tsx
import { Popover } from '@design-system/popover';
import { useState } from 'react';

export function Example() {
  const [open, setOpen] = useState(false);
  return (
    <Popover
      content={<div>Контент</div>}
      open={open}
      onOpenChange={setOpen}
    >
      <button type="button">Открыть</button>
    </Popover>
  );
}
```

## Accessibility

- **Триггер с клавиатуры** — в качестве триггера используйте элемент, доступный с клавиатуры (например, `<button>`) или элемент с `tabIndex={0}` и обработчиками клавиш. При `trigger="click"` по умолчанию поповер открывается и закрывается по Enter/Space (`triggerClickByKeys`).
- **Закрытие по Escape** — по умолчанию поповер закрывается по Escape (`closeOnEscapeKey`). Не отключайте без веской причины.
- **Семантика контента** — контейнер поповера имеет `role="presentation"`. Роль и `aria-*` задавайте в контенте в зависимости от сценария: например, `role="menu"` для меню, описание через `aria-describedby` на триггере.
- **Поддержка атрибутов** — компонент поддерживает `data-test-id` и другие атрибуты через `WithSupportProps` для тестов и кастомизации.

## Best practices

1. **Выбор триггера** — используйте `click` для выпадающих меню и действий с выбором; `hover` или `hoverAndFocusVisible` для дополнительной информации без обязательного клика.
2. **Закрытие и границы экрана** — включайте `outsideClick: true` для закрытия по клику вне поповера. Задавайте `fallbackPlacements`, чтобы при нехватке места поповер переворачивался в подходящую сторону.
3. **Контент** — передавайте в `content` любой ReactNode (текст, списки, формы). Стили контейнера (фон, отступы, тень) заданы по макету; типографику и внутренние отступы при необходимости задавайте внутри переданного контента.
4. **Отличие от Tooltip** — для коротких подсказок при наведении используйте **Tooltip**; для блоков с действиями, меню или развёрнутым контентом — **Popover**.
