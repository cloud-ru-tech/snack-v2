# Modal

Пакет `@ds/modal` предоставляет два компонента для блокирующих диалогов: готовую сборку `Modal` с пресетной шапкой, телом и футером и низкоуровневый `ModalCustom` для ручной композиции.

- [**Modal**](/components/modal/modal) — готовое модальное окно с шапкой, прокручиваемым телом и опциональным футером. Покрывает 90% сценариев.
- [**ModalCustom**](/components/modal/modal-custom) — низкоуровневая версия без предопределённой структуры: собирайте из `ModalCustom.Header`, `.Body`, `.Footer` или собственной разметки.

## Установка

```bash
pnpm add @ds/modal
```

```ts
import { Modal, ModalCustom, MODE, WIDTH } from '@ds/modal'
```
