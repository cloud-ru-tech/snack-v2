# DefaultSubHeader

Подзаголовок страницы из подписи (`label`) и копируемого значения (`value`, пропсы [`CopyLine`](/components/uikit-product-copy)). Типичный слот `subHeader` для строки с ID ресурса.

## Когда использовать

- Подзаголовок детальной страницы с копируемым идентификатором (ID инстанса, ARN, адрес).
- Нужна пара «подпись — значение» с кнопкой копирования и опциональной подсказкой.

## Анатомия

- `label` — подпись слева.
- `value` — копируемое значение (пропсы `CopyLine` из [`@ds/uikit-product-copy`](/components/uikit-product-copy)).
- `labelTooltip` — тултип-подсказка рядом с подписью (рендерится через `QuestionTooltip`).

pnpm add @ds/uikit-product-page-layout
