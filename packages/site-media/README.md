# SiteMedia

`@ds/site-media` — Видеоплеер и изображение для страниц сайта.

`SiteVideo` воспроизводит MP4, HLS, YouTube и Rutube. `SiteImage` выводит обычный `<img>` с обязательными `src` и `alt`. Секция с заголовком и медиа — `SectionMedia` из `@ds/site-section`.

## Когда использовать

| Рекомендуется                                    | Не рекомендуется                                     |
| ------------------------------------------------ | ---------------------------------------------------- |
| `SiteVideo` для плеера в собственной композиции  | Повторять каркас готового `SectionMedia`             |
| `SiteImage` для изображения с обязательным `alt` | Использовать имя файла вместо альтернативного текста |

## Анатомия

`SiteVideo` занимает ширину родителя с пропорцией 16:9. `SiteImage` передаёт стандартные атрибуты на `<img>`; размеры и оформление задаёт потребитель.

### Управление видео

До запуска показана обложка с Play. Во время воспроизведения движение указателя показывает Pause и панель. Панель MP4/HLS содержит перемотку, громкость, скорость и fullscreen. YouTube/Rutube используют управление провайдера.

`onPlay` вызывается один раз при первом фактическом воспроизведении каждого источника. `onError` сообщает об ошибке. Предпросмотр HLS использует необязательный соседний `player_sprite.vtt`.

## Установка

```bash
pnpm add @ds/site-media
```

```tsx
import { SiteImage, SiteVideo } from '@ds/site-media';
```

## Примеры использования

```tsx
<SiteImage src='/preview.webp' alt='Интерфейс сервиса' loading='lazy' />
<SiteVideo video={{ src: '/presentation.mp4', poster: '/preview.webp' }} />
```

## Адаптивность

Раскладка видео наследуется от `AdaptiveProvider`: диаметр центральной кнопки — 80 px на desktop, 64 px на tablet и 40 px на mobile. `SiteImage` не задаёт собственную раскладку.

## SiteImage

Обычное изображение с обязательными src и alt.

Возвращает `<img>`. `src` и `alt` обязательны; остальные стандартные атрибуты изображения передаются на тот же элемент.

### Когда использовать

Для изображений сайта, которым нужны явно заданные источник и альтернативный текст. Для декоративного изображения передаётся `alt=''`.

### Анатомия

Компонент не добавляет обёртку, размеры, стили или стратегию загрузки по умолчанию.

### Примеры использования

```tsx
<SiteImage src='/preview.webp' alt='Интерфейс сервиса' loading='lazy' width={720} height={405} />
```

### Props

**SiteImageProps**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `alt` | `string` | — | Альтернативный текст; пустая строка — для декоративного изображения. |
| `data-test-id` | `string` | — |  |
| `src` | `string` | — | URL изображения. |

## SiteVideo

Самостоятельный видеоплеер с обложкой и управлением для MP4/HLS, YouTube и Rutube.

Плеер занимает ширину родителя и сохраняет пропорцию 16:9. При смене `src` прежний плеер удаляется вместе с обработчиками; первый запуск нового источника снова вызывает `onPlay`.

### Когда использовать

Для видео вне стандартной секции сайта. В `video` можно передать конфигурацию или React-элемент собственного плеера.

### Анатомия

#### Controls (default `true`)

- `true` — обложка, Play/Pause и панель управления.
- `false` — видео без собственных элементов управления; подходит для фонового видео с `autoPlay`, `muted` и `loop`.

`autoPlay` включает воспроизведение без звука; браузер может его заблокировать. При `controls=true` ручной запуск остаётся доступным.

YouTube и Rutube определяются по домену URL. Их iframe подключается после нажатия Play либо при автоматическом запуске. Источник команд и уведомлений проверяется по `origin` и окну iframe. Панель провайдера и её доступность зависят от самого сервиса.

### Примеры использования

```tsx
<SiteVideo video={{ src: '/presentation.mp4', poster: '/presentation.webp' }} />
```

Клавиатура: Enter/Space на кнопке — Play/Pause; K — Play/Pause, M — звук, F — fullscreen, стрелки влево/вправо — перемотка на 10 секунд. Timeline поддерживает стрелки, Home и End. Названия элементов доступны на русском и английском; оверрайды задаются через `siteMediaLocale`.
