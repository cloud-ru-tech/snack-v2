# SiteImage

Возвращает `<img>`. `src` и `alt` обязательны; остальные стандартные атрибуты изображения передаются на тот же элемент.

## Демо

<SiteImageDemo client:visible />

## Когда использовать

Для изображений сайта, которым нужны явно заданные источник и альтернативный текст. Для декоративного изображения передаётся `alt=''`.

## Анатомия

Компонент не добавляет обёртку, размеры, стили или стратегию загрузки по умолчанию.

## Установка

```tsx
import { SiteImage } from '@ds/site-media';
```

## Примеры использования

```tsx
<SiteImage src='/preview.webp' alt='Интерфейс сервиса' loading='lazy' width={720} height={405} />
```
