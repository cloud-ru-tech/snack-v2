## Overview

Typography — это компонент для отображения текста с использованием типографических стилей из дизайн-системы. Компонент автоматически применяет правильные стили на основе выбранного варианта, размера и начертания.

Typography автоматически обрабатывает:

- **Варианты типографики**: display, headline, title, label, body
- **Размеры**: s (small), m (medium), l (large)
- **Начертания**: regular, thin, mono
- **Семантические HTML теги**: автоматический выбор тега на основе варианта
- **Стили из Figma Variables**: все стили берутся из `@sbercloud/figma-variables`

## Usage

### Basic example

```tsx
import { Typography } from '@design-system/typography';

export function Example() {
  return <Typography>Текст</Typography>;
}
```

### With variant and size

```tsx
import { Typography } from '@design-system/typography';

export function Example() {
  return (
    <Typography variant="headline" size="l">
      Заголовок
    </Typography>
  );
}
```

### With weight

```tsx
import { Typography } from '@design-system/typography';

export function Example() {
  return (
    <Typography variant="body" size="m" weight="thin">
      Тонкий текст
    </Typography>
  );
}
```

### Custom HTML tag

```tsx
import { Typography } from '@design-system/typography';

export function Example() {
  return (
    <Typography as="h1" variant="display" size="l">
      Главный заголовок
    </Typography>
  );
}
```

### All variants showcase

```tsx
import { Typography } from '@design-system/typography';

export function Example() {
  return (
    <div>
      <Typography variant="display" size="l">
        Display Large

        Label Small
      </Typography>
      <Typography variant="body" size="m">
        Body Medium
      </Typography>
    </div>
  );
}
```

## Accessibility

- Семантическая HTML структура обеспечивает совместимость со screen readers
- Автоматический выбор правильного HTML тега на основе варианта типографики
- Компонент принимает все стандартные HTML атрибуты для кастомизации
- Поддержка ARIA атрибутов через spread props

## Best practices

1. **Используйте правильные варианты** — выбирайте вариант типографики в соответствии с семантикой контента (display для главных заголовков, body для основного текста)

2. **Соблюдайте иерархию** — используйте размеры последовательно для создания визуальной иерархии

3. **Выбирайте начертание осознанно** — regular для основного контента, thin для акцентов, mono для кода и технических данных

4. **Используйте семантические теги** — позвольте компоненту автоматически выбирать тег, или явно укажите `as` для лучшей семантики

5. **Не смешивайте стили** — используйте компонент Typography вместо прямого применения CSS классов для консистентности
