# Tooltip

Пакет `@ds/tooltip` содержит всплывающие подсказки:

- [**Tooltip**](/components/tooltip/tooltip) — универсальная подсказка. Оборачивает произвольный триггер (кнопка, иконка, текст) и показывает pop-up по hover, focus или клику.
- [**QuestionTooltip**](/components/tooltip/question-tooltip) — специализированный вариант с готовым триггером «?» для полей форм и терминов.

## Установка

```bash
pnpm add @ds/tooltip
```

```ts
import { Tooltip, QuestionTooltip } from '@ds/tooltip'
```
