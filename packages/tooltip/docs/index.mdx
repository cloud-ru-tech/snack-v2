# Tooltip

Пакет компонентов для всплывающих подсказок: **Tooltip** (с произвольным триггером) и **QuestionTooltip** (с иконкой «вопрос»). Стили и анатомия — из design tokens (Figma variables).

**Version:** `{frontmatter.version}`

## Installation

```bash
npm install @design-system/tooltip
# or
yarn add @design-system/tooltip
# or
pnpm add @design-system/tooltip
```

## Overview

Компоненты тултипов показывают краткий текст или разметку рядом с элементом-триггером. В пакет входят:

- **Tooltip** — подсказка с произвольным триггером (кнопка, иконка, текст). Открытие по hover, focus, click. 12 вариантов расположения, задержки, стрелка.
- **QuestionTooltip** — тултип с готовым триггером-иконкой «?» для пояснений к полям и меткам.
- **Триггеры** — hover, focus-visible, click и комбинации. По умолчанию: hover и focus-visible.
- **Стили** — отступы, скругления, макс. ширина из design tokens.
