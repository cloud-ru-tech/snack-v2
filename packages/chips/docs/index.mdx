# Chips

Пакет `@ds/chips` предоставляет четыре компонента-чипа для фильтрации данных и пользовательского выбора.

- [**ChipAssist**](/components/chips/chip-assist) — кликабельный чип для инициации действия.
- [**ChipToggle**](/components/chips/chip-toggle) — чип с состоянием выбран/не выбран.
- **ChipChoice** — семейство чип-фильтров с выпадающим списком:
  [Single](/components/chips/chip-choice-single), [Multiple](/components/chips/chip-choice-multiple), [Date](/components/chips/chip-choice-date), [DateRange](/components/chips/chip-choice-date-range), [Time](/components/chips/chip-choice-time), [Custom](/components/chips/chip-choice-custom).
- [**ChipChoiceRow**](/components/chips/chip-choice-row) — строка из нескольких ChipChoice-фильтров с кнопками добавить/сбросить.

## Установка

```bash
pnpm add @ds/chips
```

```ts
import { ChipAssist, ChipToggle, ChipChoice, ChipChoiceRow } from '@ds/chips';
```
