# component-validation

Выбери сценарий по цели запроса и открой соответствующую справку.

| Цель | Справка |
| --- | --- |
| Оценить структуру, tier и достаточность stories, тестов и документации | [Анатомия пакета](references/tier-audit.md) |
| Проверить готовность реализации или миграции | [Порядок проверки готовности](references/readiness.md) |
| Провести аудит пакета перед MR (бывшая команда `/pre-mr-audit`) | [Аудит перед MR](references/mr-review.md) |
| Независимо проверить итоговый diff при изменении API, миграции или правке общего механизма | [Независимое ревью](references/independent-review.md) |
| Запустить конкретную сборку, линтер или тест | [Команды для одного пакета](references/fast-build-commands.md) |

Для аудита верни находки с указанием файлов и непроверенных пунктов. Исправляй найденное, когда правки входят в запрос. При проверке готовности выбирай команды по затронутым областям.
