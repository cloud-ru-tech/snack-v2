# component-planning

Выбери сценарий по источникам задачи.

- [Новый компонент](references/new-package.md). Определи API по требованиям и доступному макету. Согласуй решения о поведении, которые нельзя вывести из дизайна.
- [Перенос компонента](references/migration.md). Сверь прежний публичный API с требованиями и макетом. Зафиксируй решения о совместимости и неизвестные свойства дизайна.

В обоих сценариях план охватывает исходные данные, публичный API, затронутые артефакты, этапы реализации и критерии проверки. Критерии соразмеряй с API. Сохрани план в `tmp/agent-plans/<pkg>.md`. Если файл уже существует, согласуй его обновление. В ответе укажи путь к плану, ключевые решения и открытые вопросы. Реализация компонента требует отдельной задачи.
