# new-component-package

Определи структуру и набор артефактов по форме публичного API. При необходимости найди актуальный пример с похожим API или раскладкой. Перед созданием проверь, существует ли пакет. Используй правила зависимостей и анатомии пакета.

Для правки существующего пакета используй справку ниже. При создании пакета открой [порядок работы](references/workflow.md).
