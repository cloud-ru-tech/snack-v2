# up-cloud-deps

Последовательность шагов:

1. Найди устаревшие пакеты командой:

   ```bash
   pnpm outdated --recursive --json
   ```

2. Среди устаревших выбери только те, у которых имя содержит скоуп `@snack-uikit/*` или `@cloud-ru/*`. Сообщай об отсутствии обновлений только после проверки результатов по всем пакетам. При ошибке доступа к реестру укажи, какие зависимости не удалось проверить.

3. Обнови версии пакетов `@snack-uikit/*` и `@cloud-ru/*` до последних актуальных версий. Для прямых записей обнови соответствующие `package.json`. Если зависимость объявлена через `catalog:` или `catalog:<имя>`, обнови её в нужном каталоге `pnpm-workspace.yaml` и сохрани ссылку в манифестах. Сохрани правила диапазонов и пинов по типу зависимости. См. [packages-deps.md](../new-component-package/references/packages-deps.md).

4. Запусти:

   ```bash
   pnpm deps
   ```

5. Изучи документацию обновлённых пакетов. Если в новых версиях есть BREAKING CHANGES — найди места использования в коде и внеси необходимые правки.

6. Прогоны проверок — устрани обнаруженные ошибки:

   ```bash
   pnpm lint
   pnpm typecheck
   pnpm build:packages
   ```

   Для проверки пакетов используй `pnpm build:packages`. Если затронуты Storybook или документация, проверь и их сборку. Для точечной перепроверки используй `pnpm build:pkg <pkg>`.

7. Обновление завершено, когда все проверки прошли.

Коммит требует отдельного явного запроса.

## Замечания

- Ограничь обновление пакетами `@snack-uikit/*` и `@cloud-ru/*`.
- Если изменились токены Figma, проверь ссылки на них в затронутых SCSS-модулях.
