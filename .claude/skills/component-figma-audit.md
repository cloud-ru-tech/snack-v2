# Skill: component-figma-audit

**Триггеры:** «сверь компонент с макетом», «аудит стилей по Figma», «проверь токены компонента», «пройди чеклист аудита», «сверь `packages/<pkg>` с дизайном».

Скилл сверяет стили пакета `packages/<pkg>/src/**/*.module.scss` с **фактическим Figma-макетом** (все применённые токены и стили, не только цвет) и прогоняет структурный чеклист. Находки пишет в журнал `.claude/plan/scss-figma-audit.md` со статусами; правки применяет только по подтверждению пользователя. Идти по компонентам можно по алфавиту.

Дополняет [scss-styles-audit](./scss-styles-audit.md) (статический хардкод/циклы) Figma-паритетом и структурными проверками (box-sizing, z-index/stacking-context).

## Железное правило (без исключений)

**Не заявлять «совпало» / «исправлено» без фактической проверки.** Геометрию и визуал сверять попиксельно и по точным координатам нод (`get_metadata` даёт x/y/width/height), а не «на глаз» по уменьшенному `get_screenshot`. Если проверить нельзя прямо сейчас — писать «не проверено», а не утверждать как факт. (См. память `feedback-verify-before-claiming`.)

## Ввод

- Имя пакета `packages/<pkg>` + Figma-нода компонента (URL / node-id). Пользователь открывает нужный файл-вкладку в Figma Desktop — local MCP читает **активную** вкладку.

## Чеклист (по каждому пакету)

1. **Figma-сверка токенов (все стили).** Сверить фактические токены Figma-ноды с `*.module.scss`: анатомия (padding/gap/radius/border/размеры), типографика, цвета текста/фона/иконок, state-layer'ы, позиционирование слотов. Не только цвет.
2. **Попиксельная сверка геометрии и компоновки (до правок).** Помимо сверки токенов по значениям, **явно** снять фактический рендер компонента и сравнить с Figma-нодой попиксельно: габариты корня, позиции/инсеты слотов, gap'ы, выравнивание, overflow. Токен может совпадать по имени, но раскладка расходиться (неверный слот, лишний/недостающий отступ, сдвиг). Расхождения раскладки ловим **на этом шаге**, до правок, а не только в финальной верификации.
3. **Хардкод.** Нет `px`/`rem`/`em`-литералов, hex/rgba, литеральных opacity вместо токенов (детали и таблица замен — в [scss-styles-audit](./scss-styles-audit.md)).
4. **Копипаст осей.** Повторяющиеся `&[data-axis='value']` свёрнуты в `@each`.
5. **box-sizing.** На корне (`.root` / корневой класс) каждого компонента стоит `box-sizing: border-box`, если явно не задано другое. **Проверять только по исходнику `*.module.scss`, НЕ по `getComputedStyle().boxSizing` в Storybook** — там глобальный reset `*{box-sizing:border-box}` из `apps/storybook/.storybook/global.scss` делает live-значение всегда `border-box` и маскирует отсутствие свойства в самом компоненте. Reset — только Storybook, потребителям пакетов он не поставляется, поэтому компонент обязан нести `box-sizing` сам.
6. **stacking context (z-index).** Если у компонента есть позиционированный слот со своим `z-index`, который **геометрически выходит за границы** компонента (значок/badge/status/индикатор в углу, всплывающий бордер), корень **обязан** создавать stacking context (`isolation: isolate` либо `position` + `z-index`). Иначе z-index слота всплывает в контекст страницы и перекрывает портальный контент (Modal/Drawer/Popover). Слот `inset: 0` с z-index 0/1 (материал-паттерн `has-state-layer-as-child`, как у `@ds/button`) под это правило **не** подпадает — он заперт внутри box и не вылезает.

Легенда статусов в журнале: ✅ соответствует · ⚠️ нарушение чеклиста (низкий приоритет) · ❌ расхождение с Figma (требует правки).

## Шаги

### 1. Статический скан (без Figma)

```bash
# хардкод
grep -rnE ':[^;]*[^0-9a-zA-Z]([1-9][0-9]*(\.[0-9]+)?)(px|rem|em)\b|#[0-9a-fA-F]{3,8}\b|rgba?\(|opacity:\s*0?\.[0-9]+' packages/<pkg>/src --include="*.scss" | grep -vE '//'
# box-sizing на корнях
grep -rn "box-sizing" packages/<pkg>/src --include="*.scss"
# z-index + isolation
grep -rn "z-index\|isolation" packages/<pkg>/src --include="*.scss"
```

Для каждого корневого класса проверить наличие `box-sizing: border-box` и — при наличии вылетающего z-index-слота — `isolation: isolate`.

### 2. Figma-сверка токенов

- Распарсить node-id из URL (`node-id=3910-70` → `3910:70`).
- `mcp__figma-local__get_metadata` по ноде — структура вариантов (оси size/appearance/state/…). Если результат огромный — сохранить в файл и парсить `jq`/python, не читать целиком.
- `mcp__figma-local__get_variable_defs` по **фрейму** компонента — агрегат всех применённых токенов; по **отдельному символу** — токены конкретного варианта (изолировать цвет текста/фон/иконку).
- Для точной **геометрии** слота (позиция значка, inset, overflow) — `get_metadata` по ноде слота: даёт x/y/width/height, из них считать центр/инсет. `get_design_context` (forceCode) даёт фактическую раскладку (padding-box, translate) — использовать, когда позиционирование неочевидно.
- Сверить каждый токен SCSS с Figma-значением. Если SCSS ссылается на ключ, которого в Figma нет (напр. `width`/`height` vs `square`) — проверить компилированный CSS (`packages/<pkg>/dist/cjs/**/*.module.css`): map мог алиасить ключ. Расхождение фиксировать только если реально резолвится в другое значение.
- **После волны переименований пропов/токенов** (напр. FF-8680: `shape round→rounded`, `hasBackground→background`) — перепроверить, что `composite-var`/`simple-var`-ключи в SCSS **всё ещё резолвятся** (новый набор размеров × новые имена shape), а не молча падают/алиасят. `simple-var` @error-ит на missing-key только при **чистом** пересборе SCSS (см. «Рабочие грабли»).

**Ложные расхождения при чтении Figma-ноды — проверить ДО того, как писать ❌** (реально теряли время, память `ff-8784-figma-parity-pitfalls`):

- **Слот шире вложенного компонента.** `SLOT`/фрейм берёт габарит инстанса с его полями (у `statusIndicator 2xs` `padding:2`, слот 16, рисующий кружок 12). Размер сверять по **нижнему рисующему узлу** (`Indicator`/`line`/`border`), фрейм слота — только для позиции. Ловилось на `status`, `avatar` (инсет badge отличался на `padding/2`).
- **REST схлопывает разные переменные в один RGB.** `fills[].color` может совпасть у `textMain` и `textSecondary` (оба `(38,38,49)` без альфы). Сверять `boundVariables.fills[].id`, **не** полученный RGB (`tabs`, `tag`). Обратное — разные значения = надёжный признак реального расхождения.
- **`style.fontWeight` = вес файла шрифта, не ось.** SB Sans отдаёт 600 на всех размерах, включая те, где токен 500/550/650. Признак искусственности — одинаковое значение у всех размеров.
- **Прозрачность в `fillOpacity`, не в `color.a`.** Полупрозрачный слой = сплошной цвет + отдельное поле. `visible:false` у `header`/`focusedFrame`/`pointer` — код правильно их не рендерит, это не «пропажа».
- **Замер снят не с того узла.** Размер шрифта — с текстового узла, не с обёртки. Рамка может быть `outline` с отрицательным офсетом (`switch`, `tabs`) → `border-width` = 0 при живой обводке.
- **Расхождение мастера и выгрузки переменных** — отдельный класс (`tabs` вертикаль `l`, `tag` рамка «+N», `card` непрозрачность `activated`). Сводить код к рендеру **мастера** с меткой `TODO FF-8772`, вопрос — в `docs/figma-parity/README.md`. Если значение течёт из общего пакета (`@ds/materials` через миксин) — **не трогать** вовсе, иначе потребитель разъедется с остальными.

**Источники эталонных Figma-данных (по убыванию точности), выбирать под задачу:**

| Источник | Что даёт | Когда |
|----------|----------|-------|
| `mcp__figma-local__get_metadata` | x/y/width/height ноды и слотов, структура вариантов | Геометрия/оси — всегда первый заход (читает активную вкладку Figma Desktop) |
| `mcp__figma-local__get_variable_defs` | Применённые токены ноды/символа | Токены цветов/типографики/анатомии |
| `mcp__figma-local__get_design_context` (forceCode) | Фактическая раскладка (padding-box, translate, gap) | Когда позиционирование слота неочевидно из metadata |
| `figma-selected-block --url` (REST-in, `FIGMA_TOKEN` из `.env`) | Авто-собирает **anatomy-геометрию** (padding/gap/radius/border + дети) одним вызовом, схлопывает в `composite-var` | Быстро снять весь скелет анатомии для сверки — см. [figma-selected-block](./figma-selected-block.md) |
| REST-аннотации Dev Mode (поле `annotations`, `FIGMA_TOKEN`) | Аннотации дизайнера с точными размерами/пояснениями («Фокус теперь внутри») | Явные указания раскладки от дизайна; local MCP их **не** отдаёт (память `figma-rest-annotations`) |
| Local `.fig`-декодер (`tmp/figma/figkiwi.mjs`) | Сырые стили/переменные из локального файла | Когда MCP/REST недостаточны для точных токенов (память `figma-local-fig-decoder`) |

**Local MCP часто отваливается — remote надёжнее.** `mcp__figma-remote-mcp__get_design_context` с `forceCode:true` по `nodeId`+`fileKey` **не требует выделения** в Figma Desktop — отдаёт применённые токены (`var(--sn/...)`) + раскладку, можно гнать ре-чек самому без участия пользователя (память `ff-8772-align-to-figma`). `get_variable_defs` — требует выделения активной вкладки; `get_metadata` — по nodeId, только структура/x/y/w/h. Офлайн-декодер (`figkiwi.mjs`) — для карты/структуры; **значения подтверждать live-MCP** (пример card: офлайн дал бы `strokeMedium`=2, live — реальный `checkbox/framing/borderWidth`=1.5).

Оси/структуру вариантов брать через [figma-component-import](./figma-component-import.md). Если `get_metadata` по огромной ноде — сохранить в файл, парсить `jq`/python, не читать целиком.

Если нода не находится — активная вкладка Figma Desktop другая; попросить пользователя открыть нужный файл.

**Попиксельная сверка геометрии/компоновки — обязательный под-шаг, до правок.** Сверка токенов по именам/значениям недостаточна: имя токена может совпадать, а фактическая раскладка расходиться (не тот слот, лишний/съеденный отступ, сдвиг, неверный overflow). Поэтому до внесения правок:

1. Снять фактический рендер компонента для ключевых вариантов оси — извлечь baseline PNG (`packages/<pkg>/__test__/<C>/__snapshots__/*.png`) либо отрендерить story в Storybook и снять скриншот. Для чистого замера — по узлу компонента, не по всему `#storybook-root` (лишний viewport искажает координаты).
2. Замерить фактическую геометрию попиксельно (PIL/numpy): габариты корня, координаты/инсеты слотов, gap'ы, выравнивание, радиусы. **Не «на глаз» по уменьшенному `get_screenshot`.**
3. Снять эталонную геометрию из Figma по таблице источников выше: `get_metadata` (x/y/width/height ноды и слотов) как основной; `get_design_context` (forceCode) для неочевидного позиционирования; `figma-selected-block --url` (REST-in) чтобы одним вызовом снять весь anatomy-скелет (padding/gap/radius/border + дети); REST-аннотации Dev Mode — когда дизайнер задал размеры/раскладку аннотацией.
4. Сопоставить числа. Каждое расхождение раскладки/габаритов — в журнал как ❌ (с фактическим и эталонным числом) **на этом шаге**, до правок. Совпадения фиксировать только с показанным замером (железное правило).

Это переносит ловлю геометрических расхождений из финальной верификации в момент сверки — чтобы правка сразу закрывала и токен, и раскладку, а не всплывала регрессией после.

**Focus-рамка (`focusedFrame/*`) — расшифровка по имени слоя + обязательный явный offset.** У компонента внутри символа есть скрытый слой `focusedFrame/<...>` с rect `line (apply radius)` (обычно stroke 2px, цвет `available/complementary` = #000000). Имя кодирует позицию и наличие зазора; сверять надо все три параметра (позиция, offset, радиус):

| Figma-слой | Позиция stroke | Зазор (CSS) | Пример |
|---|---|---|---|
| `focusedFrame/regular/inside` | внутрь (align INSIDE) | `outline-offset: calc(-1 * strokeSemiBold)` | rating |
| `focusedFrame/regular/outside` | снаружи, **flush** (box focus-rect = box компонента) | `outline-offset: 0` **обязателен явно** | link |
| `focusedFrameRegular/outsideOffset` | снаружи с зазором (box focus-rect на +2px больше) | `outline-offset: +strokeSemiBold` | toggles, promo-tag |
| `focusedFrame/primary/inside` | внутрь, цвет `primary/accent` | `outline-offset: -strokeSemiBold` + `border-radius` | card |

Как отличить flush от offset: сравнить bbox focus-rect (`line (apply radius)`) с bbox компонента. Совпадают → flush (offset 0); focus-rect на +2px с каждой стороны → зазор (+strokeSemiBold). Радиус — из `cornerRadius` самого rect'а (может быть `None`/0, даже если имя «apply radius»).

**Ловушка UA-дефолта:** для `outside`-flush компонент **обязан** ставить `outline-offset: 0` явно. Без него Chromium подставляет UA-дефолт `outline-offset: 1px` для `:focus-visible` → 1px-зазор, которого в Figma нет (поймано на link: живой `getComputedStyle().outlineOffset` = `1px` при пустом SCSS). Цвет focus-stroke сверять отдельно (`290:615` = complementary у большинства; card = `primary/accent`) — не переносить card-паттерн «внутрь+primary» на компоненты с `regular`-рамкой.

**Толщина рамки — 2px не универсальна.** Миксин `@ds/materials` `with-focus-frame($appearance, $position)` зашивает толщину как `strokeSemiBold` (**2px**) — выведен из 18 мастеров `focusedFrame/*` на странице `material`, все двухпиксельные. Но **полеподобные** контролы (`search`, `fields`, `color-picker`, `dropzone`) привязаны к `brand/anatomy/focusLine/field/strokeWeight` = `strokeBold` = **3px** (память `materials-focus-frame-mixin-limits`). Для них миксин **не применим как есть** — оставлять ручной `outline` с `focusLine/field`, пока миксин не расширят параметром толщины. Толщину сверять по **фактической привязке инстанса** (нода линии `sw=3.0`), а не по мастеру.

### 3. Применение правок (по подтверждению)

- Точечные `Edit`, не переписывать файл целиком.
- Комментарии в стилях — по [writing-style](../rules/writing-style.md): сжато, без транслита («значок» не «бэйдж», «отступ» не «инсет», «Modal/Drawer» не «оверлей»), только неочевидное «почему».
- Сборка: `pnpm exec stylelint --fix "packages/<pkg>/**/*.scss" && pnpm build:pkg <pkg>`.

### 4. Верификация

- **Геометрия/визуал** — повторить попиксельный замер из шага 2 на пост-правочном рендере и показать до→после: расхождение, найденное на шаге 2, теперь должно сойтись с Figma-числом. Замерять (PIL/numpy) по узлу компонента, не «на глаз». Живой `getComputedStyle()` + `getBoundingClientRect()` в Storybook (клавиатурный Tab для `:focus-visible`) — надёжный способ снять размеры/outline/цвета. **Исключение:** `getComputedStyle().boxSizing` всегда `border-box` из-за глобального reset Storybook (см. чеклист п.5) — box-sizing по нему не проверять.
- **z-index** — live-тест: `pnpm dev:storybook` (или уже поднятый :6006), навигация Playwright-MCP на story с триггером портального overlay (Modal), клик, скриншот — слот **не** должен рисоваться поверх overlay.
- **Baseline.** Обновлять через Docker `=all` (перезаписывает независимо от порога; `=changed` пропускает малоплощадные диффы под `maxDiffPixelRatio: 0.01`):
  ```bash
  pnpm test:e2e:docker:visual:update packages/<pkg>
  ```
  После `=all` **вручную отсмотреть каждый изменённый PNG** и откатить те, где диф — только antialiasing-шум (не связан с правкой): `git checkout -- <path>`. Правки, не меняющие рендер (`isolation`, чисто-логические) — baseline **не** трогают.

  **Ловушка `=changed` при малой намеренной правке.** `=changed` обновляет PNG только если диф **превышает** `maxDiffPixelRatio: 0.01` (1% пикселей кадра). Намеренная, но геометрически малая правка (сдвиг 2px-рамки фокуса, тонкая линия, мелкий значок на большом композите) может дать диф <1% — тогда `=changed` **не** обновит baseline, а тест пройдёт на старом PNG, и baseline перестанет отражать актуальный рендер. Признак: правка визуально проверена (шаг 4, живой замер подтвердил изменение), но `git status` после `=changed` пуст. В этом случае форсируй `=all` для пакета (перезапишет независимо от порога) и визуально сверь обновлённый PNG. Пример: rating focus (снаружи-квадрат → внутрь-r2) дал ≈0.85% на `interaction-states.png` — `=changed` пропустил, `=all` обновил.

### Рабочие грабли

- **`build:packages` инкрементален по mtime → зелёный на устаревшем CSS,** если сменился только токен-пакет (`@ds/figma-variables`). Карту реальных поломок Bucket B (missing-key `@error` из `simple-var`) даёт только **чистый** пересбор SCSS — не доверять зелёному инкрементальному билду после бампа токенов (память `ff-8772-impl-plan`).
- **Пересъёмка эталонов и pre-commit хук тянут пакеты из npm-реестра на лету** (`pnpm dlx http-server`, `pnpx @cloud-ru/ft-deps-validator`). При недоступности реестра падают оба — проверять `curl -m 15 https://registry.npmjs.org/` с хоста, а не гадать.
- **Прерванный docker-прогон** оставляет `packages/*/node_modules` переименованными в `node_modules.macos-bak` → `typecheck` ловит чужие ошибки в чужих пакетах. Вернуть циклом `mv` и перепроверить.
- **После figma-правок гнать `test:unit` + `test:stories` затронутых пакетов.** Reconcile shared-пакетов меняет поведение, невидимое в SCSS: закрытый портал теперь **размонтируется** (`queryByTestId`→`null`, `.not.toBeVisible()` кидает на null — использовать `.not.toBeInTheDocument()`); дубль-рендер слота на mobile ломает `getByTestId` (strict-mode multiple → `getAllByTestId(...)[0]`). Выделение под-компонента в свой пакет ломает старые импорты в unit-тестах.

На каждый пакет — запись со статусами по 5 пунктам чеклиста, с конкретными токенами/файлами/строками и Figma-значениями. Расхождения (❌) — с предлагаемым фиксом; нарушения чеклиста (⚠️) — с оценкой влияния.

## Что **не** делает

- Не трогает `*.tsx`/`*.ts` кроме случаев, когда расхождение в них (напр. маппинг размера индикатора) — тогда с подтверждением.
- Не выдумывает токены: нет эквивалента в `figma-variables` → в отчёт «нужна помощь человека».
- Не заявляет результат без замера/теста (см. железное правило).
- Не коммитит без явной команды пользователя.
