description: Обновить зависимости скоупов @snack-uikit/* и @cloud-ru/* до актуальных версий
---

Последовательность шагов:

1. Найди устаревшие пакеты командой:

   ```bash
   pnpm outdated --json
   ```

2. Среди устаревших выбери только те, у которых имя содержит скоуп `@snack-uikit/*` или `@cloud-ru/*`. Если таких нет — останови выполнение команды и сообщи пользователю, что обновлений нет.

3. Обнови версии пакетов `@snack-uikit/*` и `@cloud-ru/*` до последних актуальных версий в соответствующих `package.json`. В этом репозитории действует правило строгих версий — указывай точную версию без `^` и `~`. См. [packages-deps.md](../rules/packages-deps.md).

4. Запусти:

   ```bash
   pnpm install
   ```

5. Изучи документацию обновлённых пакетов. Если в новых версиях есть BREAKING CHANGES — найди места использования в коде и внеси необходимые правки.

6. Прогоны проверок — чини всё, что сломалось:

   ```bash
   pnpm lint
   pnpm typecheck
   pnpm build
   ```

   (`pnpm build` = `pnpm build:packages` + сборка docs/storybook. Если обновление затрагивает только пакеты, достаточно `pnpm build:packages`.)

7. Если все проверки зелёные — апдейт считается успешным.

## Замечания

- Не смешивай обновление `@snack-uikit/*` / `@cloud-ru/*` с обновлением других зависимостей — это должно быть отдельным коммитом.
- Если после обновления поменялись CSS-токены Figma-переменных — прогуляйся по `packages/*/src/**/styles.module.scss` и проверь, что все переменные на месте (`grep '$sn-'`).
