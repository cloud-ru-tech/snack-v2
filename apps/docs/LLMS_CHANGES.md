### 📖 Документация

Созданы новые документы:

- `LLMS_COMPONENT_GENERATION.md` - полное руководство по системе генерации
- `LLMS_CHANGES.md` - этот файл

### 🔧 Как использовать

#### Для новых компонентов

1. Скопируйте `COMPONENT_DOC_TEMPLATE.mdx` в папку компонента
2. Замените `component-name` на имя вашего компонента
3. LLM.txt файл будет сгенерирован автоматически при билде

#### Для существующих компонентов

Добавьте в MDX файл после секции Changelog:

```mdx
import LlmLink from '../../../../../components/LlmLink.astro';

<LlmLink component="component-name" />
```

#### Сборка

```bash
# Development (LLM.txt файлы не генерируются)
pnpm dev

# Production (генерирует все LLM.txt файлы)
pnpm build
```
