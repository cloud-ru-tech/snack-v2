# Переключатель темы

Компонент `ThemeSwitcher` позволяет переключать тему, бренд и платформу для всей документации.

## Использование

Добавьте компонент на любую страницу:

```astro
---
import ThemeSwitcher from '@/components/ThemeSwitcher.astro';
---

<ThemeSwitcher />
```

## Демо

<ThemeSwitcher />

## Возможности

- **Тема**: Переключение между светлой и темной темой (`sn-light` / `sn-dark`)
- **Бренд**: Переключение между брендами (`sn-brandA` / `sn-brandB`)
- **Платформа**: Переключение между desktop и mobile (`sn-desktop` / `sn-mobile`)

Все настройки сохраняются в localStorage и синхронизируются:
- Между страницами документации
- С iframe Storybook историй
- При перезагрузке страницы

## API

### Theme Manager

Глобальный менеджер темы доступен через `window.snThemeManager`:

```typescript
// Получить текущую тему
const theme = window.snThemeManager.getTheme(); // 'light' | 'dark'

// Установить тему
window.snThemeManager.setTheme('dark');

// Получить текущий бренд
const brand = window.snThemeManager.getBrand(); // 'brandA' | 'brandB'

// Установить бренд
window.snThemeManager.setBrand('brandB');

// Получить текущую платформу
const platform = window.snThemeManager.getPlatform(); // 'desktop' | 'mobile'

// Установить платформу
window.snThemeManager.setPlatform('mobile');
```

### События

Можно подписаться на изменения темы:

```typescript
window.addEventListener('themeChange', (event: CustomEvent) => {
  console.log('Новая тема:', event.detail.value);
});

window.addEventListener('brandChange', (event: CustomEvent) => {
  console.log('Новый бренд:', event.detail.value);
});

window.addEventListener('platformChange', (event: CustomEvent) => {
  console.log('Новая платформа:', event.detail.value);
});
```

## Классы CSS

При изменении темы автоматически применяются классы к `<body>`:

```html
<!-- Светлая тема, Brand A, Desktop -->
<body class="sn-primitive sn-figmaStyles sn-conmonents sn-light sn-brandA sn-desktop">

<!-- Темная тема, Brand B, Mobile -->
<body class="sn-primitive sn-figmaStyles sn-conmonents sn-dark sn-brandB sn-mobile">
```

Также доступны data-атрибуты:

```html
<body 
  data-theme="dark" 
  data-brand="brandB" 
  data-platform="mobile"
>
```
