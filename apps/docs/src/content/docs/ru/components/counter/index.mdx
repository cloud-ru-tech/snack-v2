# Counter (Счётчик)

Компонент Counter отображает числовые индикаторы (счётчики уведомлений, количества элементов, метрики и т.п.) в компактном виде. Он поддерживает несколько вариантов отображения значения: обычный счётчик (count), формат с плюсом при превышении порога (count-plus) и укороченную запись в тысячах (count-k), управляемую пропами variant и plusLimit.

## Обзор

Counter — это гибкий компонент для отображения числовых индикаторов в вашем приложении. Он автоматически обрабатывает:

- **Форматирование значений с несколькими вариантами (count, count-plus, count-k)**
- **Управление порогом для формата с плюсом (проп plusLimit)**
- **Несколько размеров (xs, s)**
- **Три варианта внешнего вида (primary, neutral, red)**
- **Две цветовые схемы (accent, decor)**
- **Компактное отображение, подходящее для использования внутри других UI-элементов**

## Использование

### Базовый пример

```tsx
import { Counter } from '@design-system/counter';

export function NotificationBadge() {
  return <Counter value={9} />;
}
```

### С вариантом

```tsx
import { Counter, VARIANT } from '@design-system/counter';

export function NotificationBadge() {
  return (
    <>
      <Counter value={9} variant={VARIANT.Count} />
      <Counter value={15} variant={VARIANT.CountPlus} plusLimit={10} />
      <Counter value={8500} variant={VARIANT.CountK} />
    </>
  );
}
```

### Настройка внешнего вида и размера

```tsx
import { Counter, APPEARANCE, SIZE } from '@design-system/counter';

export function NotificationBadge() {
  return (
    <Counter
      value={10}
      appearance={APPEARANCE.Red}
      size={SIZE.S}
    />
  );
}
```

### С порогом плюса

```tsx
import { Counter, VARIANT } from '@design-system/counter';

export function NotificationBadge() {
  return (
    <Counter
      value={150}
      variant={VARIANT.CountPlus}
      plusLimit={100}
    />
  );
}
```

## Свойства

### Обязательные

- value (number) — Числовое значение для отображения. Обязательно.

### Необязательные

- appearance ('primary' | 'neutral' | 'red') — Визуальный внешний вид. По умолчанию: 'primary'.
- variant ('count' | 'count-plus' | 'count-k') — Вариант отображения значения. По умолчанию: 'count'.
- size ('xs' | 's') — Размер счётчика. По умолчанию: 'xs'.
- plusLimit (number) — Порог сокращения значения в формат v+. Например, 1500 -> 999+ для 1000. По умолчанию: 10.
- color ('accent' | 'decor') — Семантический цвет. По умолчанию: 'accent'.
- className (string) — Дополнительный CSS класс.
- ...HTMLDivAttributes — Все стандартные HTML атрибуты div поддерживаются.

## Доступность

- Семантическая HTML структура обеспечивает совместимость со средствами чтения с экрана
- Компонент принимает все стандартные HTML атрибуты для настройки
- Числовые значения являются читаемым текстом, обеспечивая осмысленную информацию

## Лучшие практики

1. **Используйте подходящие варианты — Выбирайте count, count-plus или count-k в зависимости от вашего случая использования**
2. **Устанавливайте plusLimit соответствующим образом — Настройте порог в зависимости от диапазона ваших данных**
3. **Последовательное использование размеров — Сопоставляйте размер счётчика с контекстом и важностью**
4. **Учитывайте контраст — Убедитесь, что значения счётчика читаемы на фоне**
5. **Используйте в контексте — Counter предназначен для использования внутри других UI-элементов (кнопок, тегов, пунктов меню)**
6. **Обрабатывайте большие значения — Используйте вариант count-k для значений свыше 1000, чтобы сохранить компактное отображение**
