# Avatar (Аватар)

Компонент Avatar отображает фотографии профиля пользователя или инициалы. Он поддерживает изображения с автоматической заменой на сгенерированные инициалы, несколько размеров, форм (круглая и квадратная) и различные цветовые схемы.

## Обзор

Avatar — это гибкий компонент для отображения идентичности пользователя в вашем приложении. Он автоматически обрабатывает:

- **Загрузку изображений с плавной заменой на инициалы**
- **Генерацию инициалов из имен пользователей (1 или 2 символа)**
- **Несколько размеров от очень маленького (xs) до очень большого (10xl)**
- **Две формы: круглая и квадратная**
- **Девять цветовых схем для визуального разнообразия и категоризации**
- **Доступность с правильными ARIA атрибутами**

## Использование

### Базовый пример

```tsx
import { Avatar } from '@design-system/avatar';

export function UserProfile() {
  return <Avatar name="John Doe" />;
}
```

### С изображением

```tsx
import { Avatar } from '@design-system/avatar';

export function UserProfile() {
  return <Avatar name="John Doe" src="https://example.com/avatar.jpg" />;
}
```

### Настройка внешнего вида и размера

```tsx
import { Avatar, APPEARANCE, SIZE } from '@design-system/avatar';

export function UserProfile() {
  return <Avatar name="Jane Smith" appearance={APPEARANCE.Primary} size={SIZE.Xl} />;
}
```

## Свойства

### Обязательные

- name (string) — Имя пользователя для генерации инициалов. Обязательно даже когда предоставлен src (используется как запасной вариант).

### Необязательные

- src (string) — URL изображения аватара. Заменяется на инициалы, если загрузка не удалась.
- appearance — Цветовая схема. По умолчанию: 'neutral'.
- size — Размер аватара. По умолчанию: 's'.
- shape ('round' | 'square') — Форма аватара. По умолчанию: 'round'.
- showTwoSymbols (boolean) — Отображать два символа вместо одного. По умолчанию: false.
- className (string) — Дополнительный CSS класс.
- ...HTMLDivAttributes — Все стандартные HTML атрибуты div поддерживаются.

## Доступность

- Изображения используют alt="" и aria-hidden="true", так как они декоративные
- Инициалы являются читаемым текстом, обеспечивая осмысленный запасной вариант
- Компонент принимает все стандартные HTML атрибуты для настройки
- Семантическая HTML структура обеспечивает совместимость со средствами чтения с экрана

## Лучшие практики

1. **Всегда указывайте осмысленное name — Даже с изображениями, имена обеспечивают правильную работу запасного варианта**
2. **Используйте подходящие размеры — Сопоставляйте размер аватара с контекстом и важностью**
3. **Последовательное использование цветов — Установите четкие правила, когда использовать каждый внешний вид**
4. **Обрабатывайте ошибки изображений корректно — Компонент делает это автоматически, но убедитесь, что URL изображений действительны**
5. **Учитывайте контраст — Убедитесь, что текст/инициалы читаемы на фоне**
6. **Группируйте связанные аватары — Используйте одинаковый размер и отступы при отображении нескольких аватаров**
