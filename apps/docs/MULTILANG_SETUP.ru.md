# Настройка мультиязычности в документации

## Что сделано

Добавлена полная поддержка мультиязычной документации с английским (en) и русским (ru) языками.

## Основные изменения

### 1. Настроена i18n в Astro

В `apps/docs/astro.config.mjs` добавлены:
- Настройка локалей (en, ru)
- Переводы названий в sidebar
- Автоматический переключатель языка

### 2. Обновлена интеграция синхронизации

Файл `apps/docs/src/integrations/sync-package-docs.js`:
- Поддержка структуры с локалями в пакетах (`packages/*/docs/{locale}/`)
- Синхронизация документации для каждого языка
- Обратная совместимость со старой структурой (автоматически считается английским)
- Правильная трансформация путей импортов для каждой локали

### 3. Создана структура документации

```
packages/
  avatar/
    docs/
      en/
        index.mdx    # Английская версия
      ru/
        index.mdx    # Русская версия

apps/docs/src/content/docs/
  en/
    index.mdx
    guides/
  ru/
    index.mdx
    guides/
```

## Как использовать

### Для добавления документации на новом языке:

1. Создайте папку локали в `packages/{component}/docs/{locale}/`
2. Добавьте `index.mdx` с документацией на нужном языке
3. Используйте те же импорты что и в английской версии
4. Перезапустите dev-сервер - синхронизация произойдёт автоматически

### Пример структуры для нового компонента:

```bash
# Создаём структуру
mkdir -p packages/button/docs/en
mkdir -p packages/button/docs/ru

# Добавляем документацию
echo "# Button Documentation" > packages/button/docs/en/index.mdx
echo "# Документация Button" > packages/button/docs/ru/index.mdx
```

## Переключатель языка

Starlight автоматически добавляет переключатель языка в UI:
- В навигации появляется выпадающий список с доступными языками
- При переключении пользователь остаётся на той же странице, но на другом языке
- URL меняется: `/` → `/ru/` для русского языка

## Что синхронизируется

Для **каждой локали**:
- ✅ Все .mdx файлы из `packages/*/docs/{locale}/`
- ✅ Правильные пути импортов
- ✅ Версия пакета в frontmatter

Только для **английской локали** (en):
- CHANGELOG.md → CHANGELOG.mdx
- MIGRATION.md → MIGRATION.mdx
- README.md (генерируется из index.mdx)

## Проверка

Запустите dev-сервер:

```bash
cd apps/docs
pnpm dev
```

Откройте http://localhost:4321/ и проверьте:
- Переключатель языка в навигации
- Документация Avatar доступна на двух языках
- Все примеры работают корректно
- Переключение между языками работает

## Добавление нового языка

См. подробную инструкцию в `I18N_GUIDE.md`

Кратко:
1. Добавьте локаль в `astro.config.mjs`
2. Добавьте локаль в массив `SUPPORTED_LOCALES` в `sync-package-docs.js`
3. Создайте папки для новой локали
4. Добавьте переводы документации
